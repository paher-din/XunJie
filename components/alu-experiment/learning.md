# 设计并观察 4 位 ALU

使用 SystemVerilog 实现组合 ALU。允许使用内置 `+`，无需安装工具链或编写验证支架。先编辑 alu.sv，点「运行」启用当时的作品，再拨动虚拟板或运行全部输入检查。未完成或未知输出如实保留。

输入 A、B 为无符号 4 位；M、Cin 为 1 位；S 为 2 位。F 为 4 位，Cout 为 1 位。

## 公开行为

| M | S | F | Cout |
| --- | --- | --- | --- |
| 0 | 00 | 4 位按位 NOT A | 0 |
| 0 | 01 | A AND B | 0 |
| 0 | 10 | A OR B | 0 |
| 0 | 11 | A XOR B | 0 |
| 1 | 00 | A + B + Cin 的低 4 位 | 完整和第 5 位 |
| 1 | 01、10、11 | 0（保留组合） | 0 |

逻辑模式忽略 Cin，NOT 还忽略 B。保留组合需要确定归零，不能当作 don't-care。X 表示未知，Z 表示高阻，均不当作零。这里没有减法、额外有符号标志位或动态扫描显示要求。

可直接试的公开例子：

| A / B / M / S / Cin | 预期 F / Cout | 说明 |
| --- | --- | --- |
| 1111 / 0000 / 1 / 00 / 1 | 0000 / 1 | 和是 10000，低 4 位为零，进位为 1 |
| 1010 / 1100 / 0 / 01 / — | 1000 / 0 | A AND B |
| 1010 / 1100 / 0 / 11 / — | 0110 / 0 | A XOR B |
| 1111 / 1111 / 1 / 01 / 1 | 0000 / 0 | 保留组合，不能归零以外或当作无关项 |

这些是公开预期，不是完整 HDL 答案。逻辑模式的 Cin 和 NOT 模式的 B 仍可操作，但会被忽略；界面不会悄悄改掉这些开关。

## 虚拟板映射

数字逻辑板按下列固定映射接入 A/B/M/S/Cin。位序均为高位在左、高有效；未列出的开关、按钮、复位和时钟在本活动不绑定。

| 板卡控件或显示 | 信号 |
| --- | --- |
| SW3…SW0 | A[3:0] |
| SW7…SW4 | B[3:0] |
| SW8 | M |
| SW10…SW9 | S[1:0] |
| SW11 | Cin |
| LED3…LED0 | F[3:0] |
| LED4 | Cout |

数码管和旁边的文本只读取实际 F/Cout，不需要编写扫描显示电路。混合 X/Z 会逐位保留原串，不会解码成零。

## 自由观察

「运行」会固定点击时的全部作品文件和输入，成功保留观察后才启用这份作品。再次修改代码不会自动生效；需要再点「运行」。输入变化会保存并等待短暂合并，然后对已启用作品发起真实仿真；等待新观察时不会把旧灯态冒充成新输入的结果。

只读单次支架在 t=0 设置输入，t=1ns 采样 F/Cout，t=2ns 结束（1ns/1ps）。它只观察代码，不计算正确答案。取得一次观察不代表全部行为正确。

## 全部 4096 组输入检查

「检查全部输入」固定检查已启用的作品，不读取正在编辑的代码，也不改变虚拟板输入。输入索引为：

`index = (M << 11) | (S << 9) | (A << 5) | (B << 1) | Cin`

共 4096 组：逻辑模式 2048 组、加法 512 组、保留组合 1536 组。旧检查的 2800 组采样不能代替这里。

检查用四轮真实采样：每个目标输入前先保持 1ns 的固定前驱 P0（A=0、B=0、M=1、S=00、Cin=0）或 P1（A=15、B=15、M=1、S=00、Cin=1），再施加目标输入，在 1ns 或 2ns 后记录 F/Cout。四轮分别是 P0/T1、P0/T2、P1/T1、P1/T2，计划 16384 条目标采样。同一输入在不同前驱/时刻下不一致，或结果含 X/Z、缺失、重复、格式错误，都不能通过。

四轮是有限采样，不是所有可能前驱和时刻的形式化证明；完整检查通过只说明这份已启用作品符合本次公开检查。检查的执行状态「已完成」不等于「检查通过」，界面会分别显示。

检查可以使用「停止检查」真实终止当前 Worker。停止、超时或预算中止后不会伪造通过，也不会自动重跑原检查；回到虚拟板后仍可观察当前输入。

## 预测、比较与解释

点「新用例」后，输入只作为候选保护，不会自动运行；板卡读数、已有比较和检查报告暂时隐藏。可以选一条进位或边界用例，再选一条能区分两种操作的用例，记录预测 F/Cout 和选择理由。预测可留空，直接观察也保留缺项；不要求故意预测错误。

「运行并比较」先固定这组输入、预测、理由和已启用作品，再交给真实仿真。之后修改形成新草稿，原预测不会被返回结果改写。已有相同作品 / 输入的观察、检查来源与自己报告的帮助会一同保留；应用不判断你是否在外部见过答案。解释可保存多次修订，用来说明差异、仍未解决的问题或这条用例能发现什么错误。一次正确预测或全量检查通过都不代表掌握。

波形从本次仿真保留的 VCD 读取，原 tick、信号、X/Z 和未取得的值均保留。显示缩放不会修改原时间；运行不完整时不会把波形当作完整成功。用例、结果、解释和选中的信号 / 时间范围可加入同一问题草稿，保存选择时副本；代码仍按原文选段引用。引用不会自动发送，运行与检查不会清空问题草稿。

Agent 只解释和协助验证，不修改学生代码，也不提供整份可提交答案。本阶段不生成掌握结论、教师提交或教师接收记录。
