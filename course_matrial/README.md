# 数字逻辑课程资料与前置知识

本目录为首条课后项目学习活动保留课程原始材料，并提供按概念查阅的入口。当前以 ALU 实验为改编载体，学生已经接触相关概念，但允许遗忘并在项目中补学；完整活动的设计预算为 **50–70 分钟**，尚未经过学生试用验证。

负责人已确认主线为**设计并验证 ALU 行为**，允许使用语言内置运算符；活动语言为 **SystemVerilog**。主线保留五种核心操作，减法扩展，允许带失败或缺项交付；本活动 Agent 只解释，不修改学生代码。起始工程、学生源文件和示例按 SystemVerilog 设计，旧课件中的 Verilog 示例作为补充参考，使用前核对语言与工具兼容性。

前置概念以 2026 数字逻辑课程的前三节理论课为依据。**讲过不等于已掌握**，资料中的全部内容也不自动成为本次活动的考核要求。[活动设计与验收场景](../docs/references/2026-10-23-alu-activity-design.md)提供配套说明，最终范围和验收目标统一记录在 [数字逻辑与部件设计：首条学习活动与验收目标](https://github.com/paher-din/XunJie/issues/113#issuecomment-6348000023) 的决议中。

## 原题与参考 PPT 的边界

当前实验题目使用 4 位 `A`、`B`、4 位结果 `F`，以及 `M`、`S1/S0`、`Cin`、`Cout`。题目包含逻辑操作、加减法和数码管显示；减法写有 `A > B` 条件，部分算术控制组合留空，逻辑操作及减法时的 `Cout` 含义没有完整定义。

旧 ALU PPT 使用 `aluSel[2:0]`，列出传送 A、加法、两个方向的减法、NOT、AND、OR、XOR，并使用 `nf`、`zf`、`ovf`、`cf` 四种标志位。**这两份材料不是同一套接口规范**，不能把旧 PPT 的操作和标志位直接叠加为当前活动要求。

本版控制表、每种操作的输出、保留控制组合的行为和进位约定见活动设计文档；后续扩展时需重新检查这些约定。卡诺图的 don't-care 只适用于功能约定允许自由取值的输入，不能据此把仿真中出现未知值 `X` 自动判为正确。若扩展到有符号数，还应先明确编码方式，区分无符号进位与有符号溢出。

## 按需补学入口

以出现的具体障碍选取短片段，不要求学生在活动前重读三份完整课件。

| 学生遇到的问题 | 建议先回查 |
| --- | --- |
| 不确定 `4'b1111` 和十六进制 `F` 的关系 | 理论 01 第 22、29、34 页；常量写法另看入门 PPT 第 30 页 |
| 不明白结果为何只保留低 4 位，或进位去了哪里 | 理论 01 第 23–24、41 页，再回到本活动的 `F/Cout` 接口约定 |
| 把 OR 当加法，或混淆按位与逻辑运算 | 理论 02 第 3–13、18 页；ALU 参考 PPT 第 13–14 页 |
| 不知道怎样判断输出是否正确 | 理论 02 第 15、33、46–48 页，先手算一个输入用例再与运行结果比较 |
| 想解释或优化某个逻辑表达式 | 理论 03 第 4–18、46 页；涉及无关项时再看第 23–27 页 |
| 做减法或有符号扩展时不理解负数与溢出 | 理论 01 第 25–27、35–45 页，先确认本次采用的数值编码 |
