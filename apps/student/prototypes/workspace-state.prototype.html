候选最小契约

  
对象 / 所属层保留什么不会被什么改写

   
作品与本机保存队列 / 工作区稳定对象身份、内容身份、实际内容、本机确认、远端确认；先确认本机保存，再标为已保存旧同步确认不能把后续编辑标成已同步

   
实验 / 工具运行层发起者、工具与环境版本、实际作品、参数、每次观察、完成或中断状态编辑器的新内容、后续开关操作、迟到的旧实验

   
引用 / 输入区与消息选中副本、源对象身份、来源内容身份、类型化范围；板信号／波形附实验和观察身份原文修改、工具重启、同名对象；不能定位时仍保留当时内容

   
发送意图 / 工作区点击时的问题、引用、相关作品与实验；稳定请求身份、等待／可取消／结果未知／已接收状态后续输入和编辑；等待只针对本次相关依据，不追着最新作品跑

   
教师交付 / 提交接收方点击时作品、关键证据及缺项、解释、帮助与判断来源；接收方回执是交付成功依据自动保存、重复请求、后续画像修正；后续修订另有关联记录

   
临时呈现 / 前端焦点、展开、浮层位置和待选择状态；草稿、实验输入与待发动作按已确认范围恢复不能以已显示、已点击冒充模型完成、运行成功或教师已收到

  

  
工程事件候选：WorkChanged → LocalPersisted → RemoteAccepted；RunRequested → RunFinished / RunInterrupted；ReferenceSelected；MessageRequested / SubmissionRequested → Cancelled / ReceiptUnknown / Accepted；GuidanceActionRequested → Revalidated / Expired。版本、时间戳、请求身份、课程／任务归属由宿主补齐，具体存储与工具发布协议由后续议题承接。

  
需要保持的不变量
  • 当前作品、实际实验输入、已发送引用和教师交付可以不同，差异必须可解释，过去的内容不可被新编辑替换。
  • 选择和加入引用不发模型请求；发送时引用原样保留，当前作品作为独立上下文，不冒充引用原文。
  • 本机保存失败不能显示已保存，也不能发起依赖尚未保存输入的实验或交付。
  • 断线不阻止已准备工具的本地操作；服务端 Agent 与提交只等待自己依赖的内容。工具未缓存或环境不可用不在本页模拟范围。
  • 回执未知先查询同一请求身份，不能制造第二份交付。尚未发出的意图可以取消；已被接收方接受的不承诺撤回。
  • 过期教学动作重新核对作品、实验、目标、课程权限和学生设置；页面不直接拥有教学事实。此样例只演示作品与实验两项变化。
  • 同名对象不是同一来源。引用保留原始副本，定位失败不猜测新对象。
