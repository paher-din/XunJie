## 已经由负责人确认

1. 点击“运行”才使用新代码；实验输入即时作用于当前已运行的代码。编辑器存在新修改时提示“修改尚未运行”，不强制停止编辑或清空已有结果。
2. 学生明确发送问题或提交后，固定点击时的内容；等待相关内容同步，恢复后自动完成。等待中可以取消，后续编辑不替换这次内容。
3. 同一浏览器刷新或短暂断线后，恢复已完成本机保存的作品、实验输入、问题草稿和待发动作。中断的实验不自动重跑。完整离线首次使用与多设备协同不属于本轮承诺。

已有决议继续生效：选区本身不发送问题，引用保留选中时的内容；教师提交固定交付，允许失败与缺项；教学动作执行前重新核对依据。来源见本票及总地图中的已关闭决策。

## 原型中可以操作的内容

九个逐步情形：正常进行、运行中继续修改、等待时又改了、断线恢复交付、取消待发动作、旧引用与同名对象、板信号／波形与旧动作、回执丢失、本机保存失败。

每个情形的按钮驱动同一状态模型。上方工作区允许自由操作；下方环境按钮代替异步保存、同步和实验完成事件，产品中不要求学生点击它们。设计观察区列出内部身份、对应关系、状态归属、候选事件与不变量。

“查看当时内容”可以检查已经请求发送或交付的具体内容。提交时仍在运行的实验会记为未结束，后来的结果不自动补入该次交付。同内容重复点击复用原提交；真实产品中主动新交付与网络重试仍须有不同语义。

原型使用两个预设代码样例和样例读数。板信号、波形引用用于检验来源、范围和观察身份，不执行 SystemVerilog，不生成或读取真实波形。问题接收只显示示例回执，不生成 Agent 回答。

## 已纳入决议的工程边界

- 自动保存先确认本机写入，再区分远端同步；失败明确提示，依赖尚未可靠保存输入的动作等待。
- 每次发送依赖点击时的相关内容，不等待整个工作区追上最新状态；引用的历史内容与发送时的当前作品分别表达。
- 来源以对象身份辨认，无法定位时保留当时副本，不按同名路径猜测替代对象。
- 请求结果未知时查询原请求；只有接收回执才表示教师已收到。尚未发出的请求可取消，已被接收方接受的请求不承诺撤回。
- 旧教学动作先重新核对作品、观察、目标、课程权限和学生设置。原型只演示前两项；真实运行时需要核对其余项。
- 固定交付中的关键证据、帮助情况与判断需要继承连续教学决议。原型只具备样例实验观察与缺项，不实现完整证据选择界面或教师审阅流程。

## 核对结果与限制

- 两段内联脚本语法检查通过；原型没有外部资产、网络请求或应用运行依赖。
- 在 Codex 内置浏览器中实际点击走完九种情形，观察到旧输入不会被新编辑替换、后续未同步编辑不拖住此前问题、同名对象不继承旧引用、旧教学动作失效、保存失败阻止依赖动作。
- 补充自由操作核对：取消后恢复网络不交付；同内容重复提交只有一份请求与回执；提交时实验未结束的说明保留在固定交付中。
- 本机持久化、网络同步、实验、模型与教师接收全部是内存模拟。真正刷新 HTML 会重置全部状态；“模拟刷新恢复”用于说明确认保存的边界，不证明浏览器存储可靠性或崩溃恢复已经实现。
