# 空间与身份 owner

本模块拥有个人主体、学校账号、成员资格、会话、客户端授权和成员级学习数据服务绑定；不写活动表。浏览器 wire 从 `@xunjie/contracts/spaces` 消费，生产接线见 [learning-entry](../learning-entry/README.md)。

`personal()` 幂等建立本机主体与个人空间。学校账号由管理者通过产品 CLI 建立，密码使用 scrypt 校验；会话和客户端凭据仅保存摘要，按当前成员资格和到期时间核验。退出会话、撤销连接及撤销成员资格分别生效。产品安装身份参与凭据摘要，独立恢复不复活源会话或连接。

客户端从学校入口发起 challenge，学生在学校页面登录并批准，客户端通过原 verifier 换取仅含活动读写能力的凭据。学校账号库不复制到客户端。批准不能换主体，交换不能跳过证明，已撤销凭据不能再次交换复活。

`bindMember(identity,target)` 固定环境、学习数据服务身份及配置版本；重复相同绑定幂等，换目标拒绝。`resolveBinding` 先核验完整空间和主体以及当前资格，再返回原绑定；读取失败不返回新目标或空列表。

迁移由 `spaceMigrations` 连续登记。`validate()` 校验自身绑定及账号关系；宿主登记 storage 的维护参与者、资源保留和恢复 owner。此票没有二进制课程材料，URL 引用不由本模块抓取。账号、成员、绑定和授权记录保留到显式环境删除；没有自动清理授权依据或活动归属的后台任务。
