# Agent 调试包交接

用于开发者分享选定 Agent 调用、失败案例、Prompt/模型对比和评估结果。业务数据库或工作区状态的复现继续走[业务复现流程](../../../tools/xj-dev/README.md#复现包与基线)；同时涉及两者时用引用关联两个包。这里只操作开发资料，不操作产品中的学生提交。

成员说明目标，编码 Agent 完成工具操作。平台与共享方式已确认采用本机 Phoenix + SQLite、固定包异步交接；[接入设计](../../../docs/references/2026-10-27-agent-evaluation-integration.md)维护包内容与导入边界，本文维护执行顺序和完成判据。

## 先核对能力

读取当前 checkout 的 `node tools/xj-dev/xj-dev.mjs --help` 和[团队直传说明](../../../tools/xj-dev/README.md#团队复现编号与直传)，按实际支持的包类型选择命令。2026-10-27 的实现只接受业务复现包 `xj-repro/1`；纯 Agent 调试包的采集、发布/下载适配和 Phoenix 导入尚待实现。

- **仅咨询操作方式**：说明包、编号及下面的工作流，不启动平台、登记身份或上传资料。
- **工具支持所需包类型**：按已授权目标继续下节流程，复用本人已有身份和文件权限；实际参数取当前帮助。
- **相关能力缺失**：继续整理用户已经选定且可读取的现象、版本、原始导出和本地报告，说明尚不能完成的具体阶段。报告保存在仓库外；有本地材料不等于已有可导入的正式包。不得把新包伪装为 `xj-repro/1`、猜造命令或共享编号。实现工具属于另一个开发任务，不因分享请求自动扩展。

用户已授权分享具体内容时，不重复请求同一项批准；范围不清时先从当前上下文定位，仍缺信息才澄清所选 Run/case。

## 发送选定案例

1. **固定范围。** 确定所选 Run/trace、case，或同一数据集上的基线/候选实验；提取实际 Agent、Prompt、Skill、工具、模型配置与评分器版本。结果：能明确说出本包包含的案例及必要附件，缺失输入和复现条件已标明。
2. **冻结 ZIP。** 通过已实现的采集器保存可直接阅读的 `report.md`、清单、案例、平台原生导出、评分/实验及必要附件；内容布局见[包的具体形式](../../../docs/references/2026-10-27-agent-evaluation-integration.md#分享的具体形式与交接步骤)。报告说明现象、版本、比较结果和复现条件，采集器校验引用与摘要。结果：仓库外有完整固定包，范围符合本次分享授权，不含凭据或其他未选择记录。
3. **发布并交付编号。** 按当前工具支持的命令，经既有团队私有文件链路上传。仅在发布完成后，把实际稳定包编号、简短现象和验证范围交给用户；由用户转发编号，或按明确授权发送给指定同事。结果：接收者能凭编号下载，发送者关机不影响读取。临时签名 URL 和发送者的 `localhost` 地址不是交接地址。

上传中断保留原冻结包和实际 transfer ID，沿[团队直传](../../../tools/xj-dev/README.md#团队复现编号与直传)续传；不重新采集一份变化中的内容。文件服务不可用时保留本地包与报告，如实报告未发布。

## 接收、查看与重跑

1. **下载并读报告。** 复用本人的文件读取能力，按实际编号取得包，校验摘要、清单版本和所需资源，先打开报告。未知或当前工具不支持的格式保留原文件并说明限制；下载不启动模型或业务。结果：报告可读，来源和保留范围清楚；只有下载完成时仍报告“未复现”。
2. **按需导入 Phoenix。** 用户需要查看调用树或实验比较时，用已实现的导入器建立该包独立的收件数据库，并核对父子关系、记录/评分数量和案例结果后打开本机页面。按包摘要复用已导入的副本。Phoenix 的 span ID 在实例数据库内唯一，仅新建 project 不能隔离重复记录；接收包与自己的日常开发库分开。结果：明确哪些内容已经导入及哪些只能在报告中查看。
3. **需要复现时创建新运行。** 按包中固定 case、代码、Agent/Prompt、模型与评分器版本准备独立环境；沿用当前请求对运行方式的授权，缺少真实模型或外部执行条件时明确报告。只用 fixture 的检查与真实模型重跑分别表达；导入旧结果不会自动重放调用或修改业务对象。结果：新的运行身份与实际输出、失败和评分可检查。
4. **交回修复结果。** 将新结果形成新包，关联原包、case 和基线；保留原记录。共享评价也作为针对固定 case 的新记录，不双向合并两人的 Phoenix 数据库。

收尾交付实际包编号或本地文件入口、所含范围，以及已完成的阅读/导入/重跑阶段。按任务需要停止本次启动的临时查看进程；保留仍用于交接的包和结果，清理无用临时文件。平台接入或格式尚未实现时，交付可读材料与准确缺口，不把设计流程报告为已完成操作。
