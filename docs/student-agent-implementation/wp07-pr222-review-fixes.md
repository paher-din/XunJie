## 共享额度与等待

新增 model owner migration 19；17 保存同安装换发授权，18 保存跨安装继任授权。已发布的原迁移不改写。旧学习尝试升级时补保守预留，未知费用不会按零或按时间退款。

有限默认策略为 `learning-token-budget-v1`：同费用来源滚动 24 小时 **10,000,000 输入／输出 token**，learning owner 物理并发 **8**、费用来源 **4**、主体 **1**。这些是 token 预算，不是货币报价；不复用探针每小时六次限制。输入 tokenizer 不可用时按固定请求 UTF-8 字节、协议余量和输出上限保守预留，完整最终 usage 只结算一次。

调用方先用独立 ticket 请求派发，再完成当前授权预检；队列按原接收顺序选择合格请求。未请求派发、预检失败和受限主体不能挡住其他主体；旧失败不能撤回较新的 ticket。撤回的提交尚不确定时保留可重试错误，不把 Run 永久暂停在未清理的 ticket 上。未知外发保留原尝试，不再调用 SDK。

教学 Run 等待准入时保存原 step／attempt，释放内存处理者和 lease，并持久退避后重试；扫描按 `updated_at, created_at, run_id` 轮转，20 只是单批大小。已开始调用的等待和工具 Wait 沿原身份继续。

`ModelAttempt.physicalRequestEnded` 保持原来的本地 SDK 结束语义。ledger 的 `upstream_ended` 单独决定共享物理槽释放；本地 abort／进程死亡不证明上游计算结束。未知 usage 即使已确认调用结束也保留费用预留。宿主安装参数 `learningAdmissionPolicy` 提供独立、版本化的有限配置，并参加备份还原；原 attempt 的策略不被新配置改写。

## 授权与传输恢复

跨安装读取模型结果需要当前真实成员／设备／WP01 grant／Agent route 资格，以及宿主持有的退休继任链。model owner 保存完整证据与首次出处；新 credential 本身不建立继任。accepted、在途、completed 均通过原 attempt 查询或取消，不借此 receive／dispatch。

模型持有设备接管后，Root 只把原 attempt 的读取／取消交给同一逻辑 owner 的正式继任安装。原 destination、授权、未结任务与回执都保留，另建带退休链证据的访问任务；不把接管变成新的模型调用。设备和 Root 各自核对当前成员连接、WP01 grant 与继任链，没有证明、未接管、其他 owner 或已撤销连接均拒绝。

传输 journal 属于 runtime，固定内容和完整已接受回复都不含模型密钥。小请求也预分配传输身份。丢失 begin、execute、get、ACK 回包及 Run 换代后查询同一记录；新授权只能续接已有旧传输，不能虚构旧 namespace 获得新容量。原 owner 明确确认 missing 时，保留同一 transfer ID 在当前授权下首次交付；unknown 始终不执行、不 ACK。

派发授权等纯查询恢复旧回复后重新核验当前资格，不能把旧成功当成新 permit。已经完整返回并持久消费的临时业务拒绝可由调用方以同一领域身份显式重试；commit-unknown 不按临时拒绝处理。字段顺序不改变业务关联。

有界的成员／活动权限、身份及派发权限查询每次实时执行，回复只有资格或身份，不进入效果 journal。独立 Agent 核对活动访问时不传输活动正文，避免反向权限检查放大网络往返。模型切换与 selection pin 的已完成传输仍回到原领域请求检查当前模型授权；撤销后不能凭旧成功回执继续。未知传输不走此重试路径。

网络与本地写入成本：有界权限查询为一次 capability 请求、零 journal 写入；其余小请求／小回复为 invoke、get、ACK 三次请求和 pending、received、consumed 三次本地原子写入。大消息为 begin、输入分片、execute、回复分片和 ACK；所有回复均在本地完整持久接受后才释放原 owner 的传输资源。

runtime 备份格式升为 schema 2；journal 每条独立保存为现有恢复系统加密认证的附件，metadata 只记录摘要和长度，避免累计大回复进入单个 JSON envelope。新 reader 支持原 schema 1 的隔离核对，旧 reader 拒绝 schema 2，必需 journal 缺失、null、未知格式或损坏均拒绝恢复。`recover` 分页定位遗留记录，receiving 可显式释放，completed 需先持久消费，unknown 保留并交由原领域 owner 核对。
