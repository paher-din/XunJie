# #172 非文本选区与固定结果引用：实施方案

日期：2026-11-03（Asia/Shanghai）。状态：本地实现及 Windows 验证已完成；具体证据、未执行项见[交付记录](../wp03-semantic-references.md)，Mac 按负责人要求暂缓。任务来源：[issue #172](https://github.com/paher-din/XunJie/issues/172)，继承[WP03 母规范](wp03-course-components-and-execution.md) §3、§5及相关维护/验收要求。

## 基线与前置

开发基线 `upstream/wp03@6e7d13efcf2ab30af38522e55e7ba2a7dccbef95`，分支 `codex/issue-172-nontext-references`；建立时 HEAD 与上游一致。2026-11-03 在线核对 #169、#170、#171 均为 closed，现有组件、执行和准备能力已存在；目前未发现已知前置阻塞。关闭状态不替代本票验证。

现有引用契约 `packages/contracts/src/question-drafts.ts` 仅支持 work/course-material/course-field 来源和文本/代码半开区间。正式前端 `references/model.ts`、`DraftReferences.tsx` 亦只处理此类区间。组件桥接已声明引用方法但缺少实现。执行 owner 已保留命令、固定依据、输出及结果资源；ExecutionPanel 已显示真实聚合结果，尚无语义选区。可靠草稿、动作固定依据及学校混合部署沿现有边界扩展。

## 目标和范围

实现两条完整路径：选择材料标注对象加入现有问题草稿；选择真实聚合结果中有意义的对象/单元加入同一引用区。支持多引用顺序、去重、移除、定位、重开及发送时固定依据。选择不发送、不运行、不调用模型。

本票不实现 ALU 波形、Flights 图表专用语义、第二套问题输入或草稿仓库。不改变旧发布组件字节；需要新增范围声明/选区 UI 的样例使用新版本和资源身份。

## 实现步骤

1. **版本化公共契约与注册机制。** 保持旧文本/代码 wire、半开区间与历史动作可读。增加固定的组件来源外层，包含空间/主体/活动/实例、组件版本和定义摘要、对象及内容身份；执行结果再绑定原命令/执行身份、输出内容与实际产物。范围通过 typeId/版本对应注册的结构、规范化、校验和定位适配，首批注册标注对象与聚合结果，不在主工作区增加课程专用分支。去重统一按隔离作用域、稳定来源、内容版本、规范化语义范围计算。
2. **来源所有者核验与副本保留。** 标注从可靠作品的固定状态内容读取，核对活动绑定、对象成员及选择内容；本机已保护而所属服务尚未确认的状态按受校验的固定 basis 接续，不靠客户端摘要自证。聚合结果核对当前主体资格、原命令/结果关系、产物摘要及真实资源字节，再按注册范围提取选中内容。小型摘要/副本随固定引用保存；必要大数据/图像走所属资源机制。同 owner 按其事务保留；跨 owner 使用稳定请求身份的保留/查询/确认协议，先确认保留再发布引用，丢 ACK 查询原身份，不跨库写表。失败/中断及保留释放责任登记在协议中。
3. **扩展可靠草稿与动作。** 继续使用 ReliableQuestionDraft、现有 IndexedDB 分区和 PostgreSQL 草稿修订。增加必要状态 basis、固定副本及资源保留关联，并接入动作快照，迟到回包不能覆盖后来输入。读取历史引用与创建新引用采用不同验证边界：创建必须有兼容注册器和来源授权；已保存且类型暂不可操作时，只读呈现有界、受校验的固定摘要/副本，禁用定位操作，不拒绝整份草稿，也不把未知 JSON 视为可操作范围。
4. **宿主与前端接入。** 实现 reference.select / reference.locate 的方向性请求/响应，复用连接、实例、权限及异步退休检查；进程内结果视图采用同样语义。扩展现有引用控制器和选区入口，复用询问 Agent、引用列表、移除、排序与定位提示。标注对象和聚合结果的实际选中粒度以注册结构明确固定，不能用名称、行号或屏幕坐标作稳定身份。遵循 DESIGN.md，记录实际前后界面。
5. **读取、定位和恢复。** 选中时固定的副本始终独立于当前对象；定位重新核对来源内容身份和适配能力，明确返回可定位、来源已变化或不可用。删除、同名重建、组件停用/缺失及旧连接不猜替代对象。显示固定副本不加载可执行组件。新增持久事实采用追加迁移，登记资源保留、引用验证和备份恢复；不修改已登记迁移历史。
6. **混合部署与工程接入。** 将新增来源验证/保留/读取接入 learning-entry 与 school-client 的现有预期主体校验及路由范围；学校和本机 owner 按实际归属处理，不把学校 localhost 当作学生本机。保持无课程、无组件和无执行活动的原有引用功能。

- 契约/适配：旧格式、版本、范围规范化、去重、伪造来源/对象/范围/摘要、未知类型只读恢复。
- 可靠性：本机先保护、所属服务同步、失联和丢 ACK、乱序、后来输入、多引用与动作固定；必要资源不可读/保留失败不产生虚假确认。
- 原生集成：真实 PostgreSQL/资源保存和重启；标注及真实聚合结果均验证；新增迁移、保留责任及恢复校验。跨 owner 使用真实协议负例。
- 正式桌面 Chrome：选择/定位/移除/失焦/刷新、键盘、中文输入、浅深色及窄桌面；验证来源修改/删除/同名重建、组件停用/缺适配、旧连接及真实学校路径。
