# #191：可复现 ALU 浏览器运行包实施方案

日期：2026-11-05。需求依据：[实施票 #191](https://github.com/paher-din/XunJie/issues/191)、[WP04 母票 #190](https://github.com/paher-din/XunJie/issues/190)。起点为 `wp04@0d6671e11520823d812335c33ca84fef4ff0eacc`；本地开发分支 `codex/issue-191-alu-wasm`。负责人允许方案明确后实施；Apple Silicon Mac 验收已完成并记录于 [Mac 验收记录](wp04-205-mac-acceptance.md)。

## 范围及当前事实

WP03 已合入；沿用其资源身份、版本与执行约定。本票交付可单独消费的浏览器编译/仿真运行包，不创建业务接收账本，不接正式课程 UI，不改旧 HDL 路径。后续正式活动接入仍由各自实施票承担。

现有 `tools/research/alu-wasm-probe.html` 和原生 Python 探针提供输入、四态输出、停止及 oracle 的研究先例。现成 VeriSim JS/WASM 未有本项目可重建维护链，且研究记录保留 `system.vpi` 动态加载错误，不是本票可发布依赖。原生探针仅作工程对照，不成为学生运行依赖。

## 实施顺序与交付边界

1. **源码构建先行。** 以研究产物声明的 Icarus `c7530dbcc186de2f21eacde14fd28061b885924c` 为移植起点，核对实际源码。固定源码摘要、补丁、Emscripten 与工具依赖；记录构建参数、许可证和分发要求。预处理器、编译器及 VVP 均由源码构建，不下载研究二进制作正式依赖。静态链接编译目标与系统任务注册，实际调用初始化；保留原诊断，不通过过滤或删声明隐藏问题。
2. **可复现性作为发布门槛。** 构建入口在固定环境、固定安装前缀、locale、时区与 SOURCE_DATE_EPOCH 下运行；源码路径、版本时间等非运行元数据在生成阶段处理。两个空输出目录分别完整构建，逐文件核对全部发布 JS/WASM/支持资源 SHA-256；摘要不一致则禁止生成已验证发布记录。
3. **独立运行适配。** 浏览器 ESM 公共入口接受固定源文件及 include 集合、顶层、测试支架、受支持编译选项、输入文件/plusargs 与预算；Worker 内完成预处理、编译、仿真和 VCD。返回分阶段原始诊断、四态观察、日志/VCD、终止原因及运行包/编译依据。结果缺失与 X/Z、失败均不同，退出码零不单独表示完整观察。
4. **编译复用。** 对源/include 的内容和路径、顶层、支架、选项、配置及运行包摘要规范化后计算依赖身份。编译产物带依赖身份，只有相同身份可复用；缓存是可重建材料，不承担业务结果或恢复事实的保存职责。
5. **有界执行。** 声明源输入、运行数据、WASM 内存、日志/VCD、墙钟等待与并行上限。主线程持有 Worker 终止权；同步 WASM 无限推进/零时间循环也可停止。停止/完成以一次终态裁决，终止后新任务使用新 Worker。文件输出须在运行期约束，而非只在读取结束后检查大小。
6. **可复跑工程验收。** 固定正确实现和负例独立于学生骨架保存。独立 oracle 检查全部 4096 组（含保留 1536 组），并与固定原生 Icarus 的规范化输出比较；漏进位负例为 256 错误，X 负例为 1536 未知，另验 Z、编译失败、不完整观察。验证 include/配置变化导致缓存失效、复用实际执行结果、输出/内存/时间预算、停止竞争及停止后恢复。
7. **Windows/Mac Chrome 实测与交接。** 实际加载本票生成的资源，记录 OS、Chrome、构建工具、源码及资源摘要，测量加载、编译、复用执行、停止。研究接入仅证明运行包；工程测试、浏览器验收、未执行项、教学效果分别报告。两平台消费同一固定候选，不以 Windows 或旧研究结果替代 Mac 实测。

## 发现过的问题与实际修正

- 普通沙箱调用 WSL 返回拒绝，提升执行权限后确认已有 Ubuntu，无需重装；系统依赖由负责人本人完成 sudo 安装。
- Windows 挂载盘 SDK 小文件读取慢，临时目录也曾丢失；改用 Linux 用户专用持久缓存，不依赖临时目录保存唯一工具链。
- 上游构建固化可执行后缀、本机代码生成器误继承 WASM 链接参数，均已在明确移植中修正。
- 混合 Node/Worker 产物引入浏览器不支持的 Node 静态导入；改为纯 Worker 产物，真实 Chrome 重验通过。
- 摘要校验后 Blob 模块需要显式定位 WASM；已提供固定 locateFile。include 参数按实际 ivlpp 的 `-F` 配置入口传递，不照搬原生驱动参数。
- 仅抛出输出预算异常可能被原生 stdio 吞掉，导致最后由墙钟终止；修正为先通知宿主、立即终止真实 Worker，输出/文件洪泛重验通过。
- 独立审查发现普通 stdout 会被当作观察、空预期可误判完整、内部 `pp.conf` 覆盖输入、运行包身份遗漏适配器、交付包仅在忽略目录。已改用固定支架结果文件并保留 stdout 日志，拒绝空预期与冲突路径，将适配器摘要纳入运行包身份，并将完整候选放入随分支共享的组件目录；相关负例已在真实 Chrome 重验。结果文件隔离普通日志，不声称抵御任意恶意 HDL 篡改，符合母票的防篡改非目标。
- Mac 验收按自带源码归档复建时发现归档内 6095/6163 个文件被转为 CRLF，`autoconf.sh` 在 Unix 上无法执行。已用固定 commit 的 `git archive` 重新生成 LF 归档，更新清单摘要并核对归档与固定 commit 逐字节一致；Linux x64 双干净重建摘要与交付包一致。
