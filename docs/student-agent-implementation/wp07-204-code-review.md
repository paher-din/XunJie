## Standards

最终复核没有剩余确定代码缺陷。领域写入由所属 owner 执行，迁移追加，原授权来源和业务回执保留；安装继任证明、固定连接描述与私有凭据轮换符合现有边界。未发现需要报告的代码异味。

此前三项问题已修复并增加实际场景验证：已验证的接收端可继续重试；清理事务锁定并重读当前授权，旧扫描不能覆盖新迁接；同一安装并发有效授权保留原命令身份和交接历史。文档已同步为“同一当前安装的已登记授权任一仍有效即可保留，全部失效才清理”，不再宣称撤销其中一份就停止。

## Spec

最终复核没有剩余确定需求偏差。隔离还原核对 owner 自己的记录和资源，未知物理调用保持未知；正式接管要求源退休、接收方撤权及新授权。固定逻辑 owner、原 origin、请求回执、命令、Wait 和预算不变，取消或已开始清理的记录不复活。重复接管保留接管后重新配置的连接。
