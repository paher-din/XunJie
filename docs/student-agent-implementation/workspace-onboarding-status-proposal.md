# 工作区首次引导与真实状态栏方案

2026-11-17。用户已选择“先做通用操作引导和真实状态栏”。基线为 codex/workspace-ui-alignment 的 b669c199。

## 目标与范围

让第一次进入工作区的学生知道如何看要求、开始作品、使用课程工具、求助及交付。复用旧 UI 的引导气泡、形象和顶栏状态簇，接入当前真实操作。图 1 的消抖、数码管等内容属于课程交互教学脚本，本轮不移植固定演示回复或样例运行。

## 首次引导

先显示简短欢迎和“开始了解／跳过”。开始后按“目标与材料 → 作品 → 课程工具（有时才出现）→ 求助 → 保存与提交”逐步介绍，锚定真实控件。每步可执行相应的导航动作，并可上一步、下一步、跳过；不自动创建文件、提问、运行或提交。没有课程组件时省略工具步，个人活动最后说明本机保留，学校活动才介绍正式提交。

每个主体在本机只首次自动展示，按客户端 namespace 与环境／空间／主体隔离偏好；完成或跳过后不在其他活动重复弹出。未完成保存当前步骤；活动菜单提供“工作区使用引导”供重看。存储不可用时使用会话内降级，不阻止使用。还原只读环境不自动引导。已有 Agent 待答问题出现时，让现有教学提示优先，避免两个气泡争抢注意力。

直接复用 @xunjie/ui/workspace 的 GuidancePresentation；不直接调用旧 GuideLayer 中依赖固定 CARDS 和假坐标的课程脚本。沿用 DESIGN 的 token、字体和减少动效设置。引导为非模态，不锁住编辑器和其他操作。

## 状态栏

保留当前顶部任务标题、正式提交、目标与材料及 Agent 入口。工具标签下增补紧凑状态行：活动进行中／已关闭；作品读取、保护中、已在本机保存、版本待确认、保存异常、分歧、只读；有课程组件时显示真实运行摘要和“打开课程工具”。

作品状态来自 ReliableWorkspace 的只读快照，不通过“没有错误”猜测已保存。公开本机未保护输入、确认版本及未确认请求的展示元信息；沿现有本机保护及同步成功通知更新，不新增保存命令或复制存储。状态明确只指作品，不宣称个人笔记、对话和上传都已交付。

运行状态来自已有 execution／sessions 控制器，按 requestId 去重；未知接收状态单列“运行状态待确认”，不沿用旧的 running 字段冒充实时运行。工具按钮只切换到既有工具，运行仍由各课程原有面板触发。

不显示无权威来源的 60% 或“草稿 v4／板载 v3”。“检查并构建／烧录到虚拟板”只适用于旧样例流程，当前普通活动不新增空操作按钮。确认版本来自本机学习服务，和学校提交分开说明。

## 验收与证据

修改前后保存同一活动截图。覆盖首次、跳过、重看、刷新后不重弹、主体隔离、无课程工具、学校与个人说明、只读、键盘、深浅主题及窄桌面。工程测试验证保存状态不会把未保护输入标为已保存、未知运行不标为运行中；引导不产生作品／提问／运行／提交写入。真实用户作品只读查看，使用隔离浏览器偏好验收首次引导。UI 验收与教学效果分开报告。
