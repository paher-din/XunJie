# WP08 #216：按需发现并使用平台与课程工具

本票对应[按需发现并使用平台与课程工具](https://github.com/paher-din/XunJie/issues/216)，范围与公开测试边界沿用[母票 #214](https://github.com/paher-din/XunJie/issues/214)。基线为 #215 的 `cb104e33604cbfcb8c5c4f294dd5c745e723834c`，本轮不接 MCP、Plugin 或依赖 MCP 的 Apps。

学生继续从正式学习对话提问，从原工具记录查看实际结果、来源和版本。没有新建装配面板或学生需要操作的内部步骤。

## 目录、加载与执行

`tool-discovery.ts` 收集当前获准的真实平台与课程贡献；每项保留来源、版本、用途、完整输入/结果 schema、效果声明、资源范围和 executor。常用平台工具、已固定引用指向的能力及单一当前课程组件初始可见；其他贡献由 `discover_tools` 按用途、来源、对象筛选。开放材料读取默认按需加载，固定材料引用可直接启用。

发现只返回目录，不创建执行权限。`load_tools` 只接受本 Run 已发现且仍完全匹配的 binding；选择沿原 Command 账本保存，原生工具配对完成后，下一步骤用 #215 的装配和 `segments.ts` 换段。活动后续 Run 仍可采用明确加载的同一版本；更新选择不改写旧步骤。失效版本保留异常事实，不回退同名来源。

模型别名按获准目录确定，实际派发只沿快照内的 executor；旧绑定缺少后来新增的描述性 metadata 时仍严格比对原输入、来源、效果、范围与 executor；准备和派发均复核完整绑定、当前对象条件与原 Run 许可。原 Command ID、原生 tool-call ID、Wait、未知效果、停止和晚结果归属沿 WP07，不再建执行循环。

| 边界 | 固定限制与失败行为 |
| --- | --- |
| 内部目录 | 最多 512 项、2 MB；所有者读取最多 5 秒，无自动重试 |
| 发现页 | 1–8 项、最多 6000 字节，最多 8 页；超过页上限保留 `limitReached`，不伪称全部覆盖 |
| 游标 | 固定主体、活动、筛选和目录摘要；重读同页稳定，变化拒绝旧游标；重算页边界以拒绝修改偏移或页号绕限 |
| 加载 | 每命令最多 8 项、活动同时选择最多 32 项；未发现、已撤销或变化的完整绑定不加载 |
| 模型工具集 | 最多 64 项、schema 总计最多 24000 字节；容量不足明确暂停，不静默删约束 |
| 原运行预算 | 每次发现、加载、范围读取均为原工具 Command，计入原次数、串行 lane、时间及总预算，停止后不发新调用 |

应用使用完整同步 JSON Schema 校验，包含本地引用、正则、2019-09 和 2020-12；外部未解析引用、异步 schema、未知必需关键字及未经核实的 native strict 明确拒绝。三协议保留实际支持的定义，不静默丢约束，不把本地校验宣传为原生 strict。

## 大结果与原件

完整 outcome 先存入原 Agent 资源并建立保留关系，再向模型配对。`tool-results.ts` 给模型最多 8192 字节的合法 JSON；大结果提供可读片段、精确字节范围、原 Command、完整原件摘要和 `read_tool_result`。旧的小结果反馈字段位置保持兼容。

原件以原 Command 与 SHA-256 固定完整 result 的 canonical JSON UTF-8 字节；范围读取必须同时指定两者，最多返回 4096 原始字节，base64 保留精确字节，另给不冒充完整字符边界的 preview 和继续偏移。链接与任意 resource ID 不作为读取权限。读取必须属于同一主体、活动、原 Run，沿不可变工具结果事件选择指定 SHA 的保留资源；未知版本不回退最新结果。原始效果的 accepted/unknown/completed 状态单独保留。派生范围读取沿原 Command 指针逐层复核来源绑定，停止与授权在读取前后复核。完整文本、结构化数据及 PNG 原件/既有模型图像引用均随原 owner 保留，重启不换来源或重跑工具。维护清单 v2 纳入每个历史结果资源，继续验证 v1 维护材料；较晚完成与停止清理不改写旧 SHA 字节。

新段只带有界工具反馈与固定出处，完整原件留在资源与快照事实中。新段保留当前已接受的问题和已完成操作事实；不把 portable assistant 事实误作未闭合的供应商思考轮，也不搬运旧 reasoning、签名或 tool-call ID。
