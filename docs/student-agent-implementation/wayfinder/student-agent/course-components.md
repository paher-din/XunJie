# 课程组件与生成内容的接入和恢复

来源：[GitHub 最终决议](https://github.com/paher-din/XunJie/issues/117#issuecomment-6409950554)。已于 2026-10-29 收录最终决议正文。正文中的“本次”“尚未”等状态指该票收束时；研究结论、版本与实测不等于当前实现或新的验收结果。后续确认见[本地决议索引](README.md#后续确认)。 本地当前术语为“课程组件”，正文保留决议时的“课程工具”旧称；模型可调用操作称 Agent Tool。

本地配套材料：[组件宿主详细设计](../../references/2026-10-26-course-tool-host-proposal.md) · [OpenIntelligentUI 与 MCP Apps 研究](../../references/2026-10-26-course-tool-host-research.md)。

## 原决议

Robert 于 2026-10-26 对完整方案答复“符合，按此形成决议”。本票确定最小交付与宿主契约，承接[本地优先执行](https://github.com/paher-din/XunJie/issues/114#issuecomment-6363162710)和[工作区交互与状态](https://github.com/paher-din/XunJie/issues/116#issuecomment-6370870664)的已确认行为，不重新决定自动保存、实验运行、固定引用或提交。关闭表示设计决策完成，不表示工具平台、浏览器集成或教学效果已验收。

### 1. 课程配置、可复用工具与活动实例分开

- 课程发布内容选择固定工具版本，携带本课配置、开放资源、教学策略及运行方案。CoursePack/CapabilityPlugin 可继续作为实现命名，但不据此建设通用插件市场。
- 可复用工具定义保存界面或算法、输入输出与状态结构、资源和环境需求、样例及自检。开发者和教师借助 Agent 创造的工具使用同一接入契约，允许真正的新界面、新算法和流程。
- **教师工具库**保存工具草稿与可用版本，供不同课程再次选用。创建即保存草稿，检查通过形成可用版本，教师选择用于课程并随课程发布；入库与发布给学生分开，不要求教师手工搬运包或编写运行清单。
- 活动实例绑定课程、任务、学生及固定工具版本，保存作品引用、交互状态和运行/观察引用。教师预览、不同学生、不同活动拥有独立实例，共享定义不共享学生进度。
- 临时教学页面是活动中的内容实例，不必先发布完整插件。教师选择复用时提取可复用实现和示例数据，不把学生答案或实验状态混入共享工具。

### 2. 平台执行确定性准备，Agent 负责理解与创造

| 时机 | 平台直接完成 | Agent 参与 |
| --- | --- | --- |
| 选择已有工具 | 读取声明、组合配置、准备兼容依赖、执行固定自检 | 理解教学需求，推荐工具与参数 |
| 创造或修改工具 | 构建、接口/资源校验、执行示例并报告具体失败 | 生成或修正界面、算法、说明、声明与示例 |
| 加入课程和课前预览 | 检查课程配置、材料与运行安排，创建独立试用实例 | 协助教学适配、解释问题和改进内容 |
| 学生进入活动 | 检查实际设备，执行已有准备、查询与恢复程序 | 需要语义理解或说明时介入 |

Agent 可以调用准备命令，但这些程序的执行、状态和结果不依赖模型持续在线。相关代码、依赖、配置或环境变化才重做受影响检查，已就绪工具的每次打开不变成一次生成流程。自动自检不代替教师对教学适合性的判断，教师预览也不代表全部学生设备已经通过。

“工程接入”指平台开发者补充尚不支持的系统、硬件访问或执行控制能力。在已支持且允许装包的环境内添加兼容依赖属于装配，新课程、新界面或新算法本身不要求改主工作区。准备失败保留已完成配置和进度：程序修复已知依赖问题，Agent 修正需要理解的生成内容，新增平台能力的缺口明确交给工程；结果未知或有副作用的操作沿原身份查询，不盲目重跑。

### 3. 最小清单与统一宿主语义

工具清单至少表达稳定身份和固定版本、宿主 API 版本、入口与资源内容身份、输入/输出及状态结构、所需能力、示例和自检。需要执行时增加锁定的环境/依赖及有限作业或持续会话声明；无需执行的工具省略执行部分。创作侧保存源码和构建依赖，学生装载准备好的固定资源。

兼容已有宿主 API 与环境的新工具按声明动态加载，无需重新构建主前端。内建组件可直接注册；教师或第三方界面在隔离页面运行，计算进入获准 Worker 或执行器。来源不自动授予权限，实际能力由声明、课程策略、当前主体及操作依据共同约束。

组件、生成页面与外部应用通过不同适配共享以下语义，不各自维护一套作品和恢复规则；这里确定字段含义与顺序，具体编码在实施规范中固定。

| 接口组 | 必需语义 |
| --- | --- |
| 绑定与生命周期 | 工具/版本、活动/实例、允许能力；每次挂载独立连接身份；准备、就绪、失败、关闭视图分开 |
| 内容与状态 | 读取工作区对象，按所依据的状态身份提交变化；工作区分别确认本机保存和远端接收；恢复只使用已确认状态 |
| 命令与执行 | 参数与效果类型、稳定请求身份、真实输入与范围、可查询结果/回执；停止和持续会话能力按实际执行器声明 |
| 观察与教学事件 | 结果绑定输入与运行；控件变化、学生回答、预测、确认分开，不自动将变化转成模型请求或掌握证据 |
| 引用与语义锚点 | 稳定来源、内容身份、类型化范围、当时副本与定位能力；来源变化或不可用时保留副本，不猜测替代对象 |

接口按需实现，不强迫每件工具都有面板、编译器或评测器。工作区确认可恢复状态，工具可以持有即时交互内存但不能另立可变权威；旧连接或乱序写入不能覆盖新状态。执行器掌握真实运行与检查点，重新打开页面或恢复滑块不等于实验继续或重跑。

非文本引用由工具提供语义适配：波形使用运行/观察、信号及时间范围，图表使用系列和数据点/区域，画布使用对象身份或区域，并提供 Agent 能读懂的摘要及必要图像/数据副本。跨域 DOM 坐标不能冒充稳定语义。宿主统一处理引用展示、去重及草稿；工具缺少所需恢复或选择能力时，接入检查如实指出，不以页面能显示宣称全部能力就绪。

### 4. 工具版本更新由教师选择，保留既有活动

新版本完成检查、成为可用版本后，页面提示哪些课程任务仍在使用旧版及当前版本，教师选择是否同步、同步哪些任务；编辑草稿不自动改变课程。

同步先检查所选任务的配置与环境兼容，成功后更新该任务供后续新活动使用的版本。**新开始的活动使用新版，已经开始的活动继续原版；本轮不加入进行中活动跨版本迁移。** 按任务反馈已更新、未选择或失败，失败保留原绑定，不能以部分成功冒充全部完成。

关闭视图、停止运行、停用工具、移除库入口和删除学生数据是不同操作。关闭视图释放连接与订阅，运行按声明生命周期处理；仍被课程或活动引用的固定资源保留供使用和恢复。不能再运行时保留可读作品、引用和历史结果，并明确无法恢复的交互，不清空进度或声称原实验仍在继续。

### 5. 生成内容可以使用开放能力，修订优先保留输入

临时交互页面默认服务当前活动，可读取获准数据、调用课程开放的实验能力并保存状态。修改学生作品继续遵守学生请求/采纳和课程帮助策略；教学示意不能冒充真实实验结果。

生成阶段先预览，通过结构和能力检查后启用交互。Agent 修改已经操作过的页面时形成新内容版本，优先原位更新、保留可对应输入；无法兼容时保留原页，另开新版并说明差异。旧实验、引用与交付继续绑定原内容。任意脚本内部变量不自动成为可恢复状态，收纳和重开通过显式状态契约完成。

### 6. OpenIntelligentUI、MCP、MCP Apps 与 Skills 的位置

- 局部复用 OpenIntelligentUI 的片段处理和渐进展示机制，渲染层保持可替换；基于已有 iframe 桥接补齐实例、状态和引用。不移植整个 React renderer、聊天后端或 CopilotKit 状态，Websandbox 不作为必要依赖。具体抽离、许可保留及浏览器行为由实施验证。
- MCP 接入外部工具和资源；MCP Apps 适配符合其规范的外部交互界面，映射到同一活动与能力契约。不要求每件内建或教师工具都先实现 MCP 服务，不承诺任意 Apps 页面天然具有循阶的恢复和语义引用能力。
- Apps 的模型上下文更新与工作区保存确认分别表达；MCP 传输重连不承担学生进度恢复。Core、Apps、SDK 和具体宿主版本分别固定与核验，draft 能力不能冒充稳定互操作支持。
- Skills 提供操作与教学指导，不替代权限、运行宿主或状态协议。说明文件引用资源不自动授予访问权。

### 7. 学生侧只获得开放材料和反馈

教师私有原文不进入学生工具包、前端资源、学生侧 Skills 或学生 Agent 上下文。教师可以另行发布适合学生的说明、提示或材料版本；私有评测只返回课程允许的结果与反馈，工具元数据和 MCP 可见性标记不代替资源访问检查。

需要保密的评测材料不随运行包下发学生设备，由教师侧或课程明确配置的受控评测服务执行；学生本地练习使用开放样例并沿既定本地运行方案开展。没有私有评测需求时，不因此增加远端评测服务。

### 8. 契约例子与证据

- **ALU**：编辑器、虚拟板和波形视图共享工作区依据；每次观察绑定输入，波形引用表达信号与时间范围，生成比较页读取获准观察并调用允许验证。
- **数据分析**：教师创建新算法和图表，入库后用于不同课程数据；各学生独立保存筛选、图表选择、作品和运行。兼容依赖进入已有环境装配，主工作区不新增课程分支。
- **材料标注**：用内容、状态、引用和锚点形成结构化作品，无需伪造编译或实验步骤。

后两项是检验契约的设计反例，不是已选定、已接入或已验收的第二门真实课程。
