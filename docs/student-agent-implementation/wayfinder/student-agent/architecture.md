## 原决议

日期：2026-10-27（Asia/Shanghai）。

本票的产品边界和架构取舍已收束。负责人已在连续讨论中明确产品要求并委托工程判断，本轮进一步要求核对是否还有待讨论事项、能否关闭。按本票范围复核，未发现必须继续留在本票的已知产品分叉；以以下长期目标设计交接后续存储、迁移与实施规划。实际新问题出现时按证据修订，不预设“先用简化内核、以后再换完整框架”。

### 1. 领域事实、模块和部署

- 学习空间（个人/学校）、学习活动、工作区作品、模型运行、工具执行、学习证据、画像判断与教师交付分开。学生面对连续 Agent；模型会话与调试平台不能成为教学事实的唯一存储。任务完成不等于掌握。
- 同一客户端切换逻辑隔离的个人/学校空间。六个可组合单元为客户端、空间/课程、学习数据、教学协调/Agent、模型连接、工具执行；同机可合设进程，支持个人全本地、学校统一和本地/云端混合部署。
- 部署维护者配置服务位置；学生不在学习过程中配置数据库、执行节点或 Agent 服务拓扑。学校空间内学生始终可以选个人模型；这不改变课程、作品和交付的空间归属。
- 课程实验继续由教师设计运行方案，尽量本地，只有课程明确配置的替代路径可转远端。产品部署能力与开发团队的小型共享环境分别判断。
- 学生关页面后，已接收明确请求可在预算内完成并保存；依赖浏览器时记录等待/中断，不另换节点重跑。离开后不新增主动教学推理。本机服务也退出时不能声称继续运行。

### 2. 长期内核与可靠运行

长期采用**自有持久 RunDriver + 直接协议 SDK 薄适配**。RunDriver 唯一负责请求内的步骤、调度、等待、取消、预算与恢复；RunStore、ModelGateway、ToolExecutor 分别记录运行状态、原生模型结果和实际执行事实。三协议沿用已有模型连接决议，原生 reasoning/签名/工具身份按路线保存，不能降格为通用文本后再拼回。

选择理由是运行阶段可直接表达完整原生结果、固定命令、回执、预算与取消，本机和共享部署沿用同一语义，减少框架消息/恢复模型的桥接。项目因此长期承担领取代际、持久队列、等待/唤醒、预算账本、并发、记录升级等维护成本。Pi durable 整体托管是有实际收益的替代；本票没有证明自研总成本更低，也不以“教学事实自有”推导必须自研。Pi core 与 Harness 的已有能力和缺口保留在研究证据中。

完整响应可靠保存后才产生执行意图；命令绑定固定输入与稳定身份，在执行点复核资格和对象条件。未知效果查询原命令，不更换身份或节点重放。每个 Run 同时一个有效推进者；接收、待发记录与状态变更在所属存储内原子提交，跨服务靠稳定引用和回执衔接。取消、工具停止与效果撤销分别表达，晚结果保留事实但不复活终态。

### 3. 完整 Agent 的能力和上下文

- **课程组件**是课程装配单元，可贡献零个或多个 **Agent 工具**；Plugin 是分发层，Skill 是指导说明，Command 是实际执行意图与回执，彼此不混用。统一宿主承接状态、命令、观察、选区和生成内容，延续已定教师组件库与版本更新规则。
- AgentDefinition 固定角色、Prompt、能力、上下文、输出和预算。每个 step/attempt 绑定实际装配与上下文内容身份；能力变化追加新快照，恢复不套用后来配置。
- 工具注册表按主体、空间、课程、活动和执行环境筛选，绑定真实 executor。JSON Schema 经路线投影并由应用校验；必需约束不能表达则明确缺项。结果区分完成、业务失败、未派发、已接受未完成、未知效果与大内容引用。
- Skills 使用 SKILL.md 说明包与按需装载，记录内容版本；读取脚本不等于运行、allowed-tools 不创建权限。课程内允许学生自愿添加个人 Skill/MCP，遵守课程规则，不要求普通学习先配置扩展。
- MCP 明确接入 tools/resources/prompts，Apps 沿课程宿主契约处理；连接、凭据、能力变更和断线有各自生命周期。Plugin 可贡献组件、工具适配、Skills、Prompt 与连接配置模板，不建立新的运行权威，不默认加入通用 hook 或多 Agent 团队。
- Prompt 分开平台规则、运行模式、课程约束、学生意图、Skill 指导与事实材料。每步上下文优先保留当前意图/引用、规则、未结命令与等待、实际结果，再检索相关历史与记忆；压缩保留来源、矛盾、未知和未结事项。改变路线或固定前缀时结清配对、建立新原生段。
- Memory 分开事实、候选推断和偏好，保留来源与纠错；同课跨任务积累，跨课不自动迁移学科掌握判断。学生异议不改写原始事实或教师正式评价。

### 4. 新消息、学生过程显示与自主学习

**新消息默认 steering，可在设置中改为排队。** 普通 steering 立即可靠接收，在同一 Run 调整当前工作；等完整模型响应结束后采纳，不向已经发出的请求插入文本。循阶增加未启动工具派发前检查：新引导先到则为旧调用结算明确未执行结果，已开始调用按真实结果收束。此检查是本项目工程增强；Harness/Pi 普通 steering 实际等待完整工具批次结束。长作业已返回接收回执后，可以唤醒对话处理补充，原作业单独跟踪。

排队等完整当前轮正常结束后按序作为新轮处理，设置只影响未来消息。当前提问的关联回答直接恢复等待；另发 steering 可替代未回答的旧 Wait，晚到回答不推进失效等待。收尾与输入接收按同一序列裁决；失败、取消和预算耗尽保留所有未消费输入为暂停项，终态后的继续建立关联后继 Run，不自动重放旧操作。

**学生能看到工具调用、思考摘要和真实状态。** 默认紧凑显示，展开学习相关参数、实际结果与来源；原生摘要与面向学生的过程说明分别标注，没有摘要不伪造。raw reasoning、签名、内部 ID 和协议 JSON 不直接铺进学生面板；课程允许的帮助程度同样适用于摘要与工具反馈，折叠不能代替该边界。IP 保留短状态/回应入口，详细过程在对话中查看，不抢焦点或强行滚动作品。

**个人空间可直接自主学习，无需先建课程。** 从问题或选定资料建立活动，课程绑定可选，复用公共能力与同一 Agent 基础；按学生目标和既定主动性偏好提供解释、练习与帮助，不套用虚构课程规则。个人记录按活动/明确延续的目标组织，不自动进入学校或跨主题迁移学科判断。

### 5. 交付、评估与开发协作

回答区分依据、推断和未知；教学产物经结构、资源、状态与依赖检查后展示，修订有预算。具体能力表已给出平台工具、一个 ALU 组件的多个工具、个人 MCP、产物校验及后台画像任务；完整合成请求走查包含实际 Prompt 示例、上下文/Skill 装载、工具结果、引导、失败修订、等待和交付，并检查无课程、大结果、换模型、版本更新及观测失败分支。

采用**本机 Phoenix + SQLite**、同仓可选 OTel/OpenInference 集成和 TypeScript 评估工具。默认关闭观测，真实数据/平台库/秘密留在仓库外，启用后默认只到本机；不要求常驻大服务器，不使用付费版。Langfuse 同样是可本机运行的合格候选，当前选择基于同场景功能、操作、协作与资源试用，不作普遍质量排名。

团队分享选定 ZIP 调试包，含可读报告、manifest、cases、traces、评分/实验、配置和必要附件，沿团队文件链路返回稳定编号；接收方先读报告，再按需导入独立数据库，显式重跑形成新 Run/新包。流程已纳入 xunjie-development；纯 Agent 包的采集/导入及现有包类型适配尚待实施，不冒充现有 xj-repro/1 已支持。

### 6. 复用、替换和证据边界

复用可靠本机保存、固定命令、回执、节点执行、既有 UI 组件与明确的版本机制；重建它们与学习活动、模型步骤和教学交付的关联。统一全局个人聊天与课程辅导的运行基础，替换课程硬编码装配、学生手动确认/冻结必经流程，以及只支持文本回合的旧 Agent 入口。保留旧数据，只迁移实际需要的对象；不承诺全量旧接口兼容。

已有证据包括官方资料/固定源码研究、真实库或源码配合替身的内核探针、11 个局部 steering 探针、Phoenix/Langfuse 小型合成案例的本机 UI 与独立实例转移试用，以及合成交互示意和设计走查。各自的范围、失败与未测项分别记录，不能合并算作生产验收。**真实模型行为、跨服务/进程恢复、目标设备与浏览器矩阵、教学效果仍需实际验证。**
