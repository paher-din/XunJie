# [WP08：新增能力与资料的跨机使用、备份和接管](https://github.com/paher-din/XunJie/issues/221)

规范为 [#221](https://github.com/paher-din/XunJie/issues/221) 与母票 [#214](https://github.com/paher-din/XunJie/issues/214)；本票是 WP08 最后一张交付票。基线为 `84bfefd0`（已含 #215–#220 与 #219 的整合结果）。本票不新增 MCP、Plugin、依赖 MCP 的 Apps，也不改任何已发布迁移的字节。

## 跨服务接线

问题不是缺少能力，而是独立 Agent 安装与资料宿主之间仍有几处只在本机成立的隐式绑定。

- `teaching.dependencies` 的公共工具作用域原来用严格 schema 丢弃 `skillState`，因此跨机执行 `search_materials` 时 Skill 附件无法按原步骤选择读取。现在作用域用 `teachingSkillStateSchema` 校验并带上固定 `skillState`，仍只传输数据、不传输本地 guard 函数；超预算或伪造字段在边界拒绝。
- `teaching.agent` 增加 `facts.read`：明确偏好读取使用 `studentFactsReadInputSchema`/`studentFactsReadResultSchema` 定型，保留原事件、内容版本、作用域与复核链，不再依赖本地对象越过活动归属。
- `teaching.agent` 的 `skills.read` 允许携带原步骤的固定选择引用。Agent owner 用该引用重解析当前活动资格，再读取固定附件；伪造、重复或停用的选择不能扩权。`agent-transfer-journal` 把 `facts.read` 与 `skills.read` 一并纳入可重查的只读传输，断线后仍沿原来源、主体与操作身份核对。
- 资料宿主的 `createTeachingTools` 在读学生事实和 Skill 附件时不再绑定本机 `teaching`，而是经 `teachingFor(identity, activityId)` 取活动固定的 Agent owner。本机与独立安装的 Agent 走同一窄接口；执行点仍复核当前资格。

## 恢复来源闭包

各 owner 通过只读维护接口给出版本化来源清单（`xunjie.owner-sources/1`）：主体、空间、活动、owner、固定身份、版本、摘要和资源原字节。清单只枚举已保存事实，不重跑模型、工具、PDF 转换或摘要重算。

- 学习数据 owner 覆盖个人资料及不可变版本、PDF 原件/读取记录/页图摘要、问题草稿与固定引用、ActionIntent、Command、结果、停止、原生/通道执行、等待与预算相邻事实。
- 教学 Agent owner 覆盖定义与解析装配、段切换、快照、步骤、命令、Wait、预算、事件及历史结果资源、压缩及来源、Skill 定义/版本/选择/装卸、学生明确事实、提问/回应、输入修订/控制、模型切换与分片。
- 新增 Skill 装载校验：每条 `teaching_skill_loads` 必须能回到原固定包的同一版本、同一路径、同一摘要和精确字节范围；缺少原件或改写装载内容都会让恢复校验失败。
- 来源清单作为 `OwnerBoundaryMaterial.sources` 的可选附加事实进入加密备份；旧备份没有该字段时仍按已发布格式验证，恢复后不补造历史证据。

## 跨安装恢复集合

新增认证过的恢复集合：一个 `recovery-set.json` 以 HMAC 绑定各原安装已密封备份的 `manifest.json` 摘要、构件清单和 `boundaryAt`，并把每个成员的加密构件复制到集合内。验证时逐个调用既有 `verifyRecovery`，比对原始摘要、构件与身份；缺成员、缺原件、损坏或引用不匹配在还原任何成员之前整体拒绝。`restoreRecoverySetBundle` 先全量验证再逐个隔离还原，保持原业务身份，禁止模型、工具、PDF 转换和摘要重算。CLI 提供 `backup-set` / `restore-set` 入口。

## 接管与凭据门禁

沿用安装继任、源退休与接收方 fencing。备份仍保留加密凭据历史，但目标安装不复活源秘密：新宿主必须通过原设置重新提供对应路线凭据并取得模型/执行服务当前授权，才能派发。隔离阶段只读；正式接管后旧安装与旧处理者失权，未知效果只核对原操作，Wait、预算与晚结果继承原事实。普通重启保留本安装的有效授权。隔离还原测试增加断言，证明源模型凭据没有进入继任安装的私有凭据目录。

## 兼容

已发布迁移 SQL 保持原字节；新增能力只追加事实与校验，不改旧清单形状。旧备份按原格式验证，不能证明安全排空的未结物理效果继续阻止备份或接管。
