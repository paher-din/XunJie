## 4. HR-DL-03：X/Z 与有限波形

### 输入与获准事实

- 学生问题：`为什么当前输出还有 X/Z，我下一步该观察什么？`
- 当前合成源码：四位 `F` 由一位表达式 `A[0]` 赋值。
- 当前 Build：成功，无诊断，`resetN=1`。
- 当前最终信号：`A=0000001000010000`、`leds=xxxx000000000010`、`segments=00x001z`。
- 当前 trace：只保留 2 帧，原 sampleCount 为 12、droppedFrames 为 10、coverage 为 incomplete。
- 获准证据类型：源码、Build、最终信号帧和有限 trace。

### 模型完整可见正文

**content**

> 在确认过的顶层代码里，`F` 只接到了 `A[0]`，所以 `F` 的高位没有被任何逻辑驱动，显示为 X/Z 是可能的。你下一步先自己观察：二进制开关里 `A` 的当前值是什么，以及 `leds` 中哪些位是已知的 0/1、哪些位仍是 X/Z；再把它们与 `A[0]` 的预期值逐位对照，判断“未驱动”能解释哪些 X/Z。

**rationale**

> 构建成功且复位为 1，说明不是工具或复位初始化失败；顶层 `F = A[0]` 只驱动最低位，高位未连接可解释 LED 高位的未知态，同时数码管 X/Z 需要学生自己结合该未驱动状态去进一步定位。提供观察步骤而不给出完整修改方案。

**expectedStudentAction**

> 学生自己读取当前开关值和 LED 位，标出已知与未知位，并把 `A[0]` 与 LED 最低位对应起来，说明哪些 X/Z 可能来自未驱动的 `F[3:1]`，然后决定下一步检查或修改什么。

**assistanceContext**

> 已确认顶层为 `module top(input logic [3:0] A, output logic [3:0] F); assign F = A[0]; endmodule`；构建成功，复位为 1。信号帧显示 `A` 为 `0000001000010000`，`leds` 为 `xxxx000000000010`，数码管段为 `00x001z`。

**unresolved**

- 数码管段仍含 X/Z 的具体来源未确认。
- 学生尚未自行核对开关值与 LED 已知/未知位的对应关系。

### 已发现的技术疑点

SystemVerilog 中，将一位无符号表达式赋给四位向量通常会按赋值上下文进行宽度扩展；`F = A[0]` 本身不等同于 `F[3:1]` 没有驱动。因此模型关于“高位未驱动并显示 X/Z”的因果解释很可能错误。有限波形中的 X/Z 也可能来自 `F` 以外的连接、映射、数码管逻辑或未提供的上下文，当前证据不足以锁定原因。

### 自动边界结果与人工填写

- 引用：仅使用获准源码、Build、信号帧和有限 trace。
- 模型声明：不含完整答案、不写学生作品、不运行代码、不作正式评价。
- 实际调用：1 次；elapsed 4,301 ms；actual usage 为输入 1,933、输出 642 tokens。
- 人工结论：`有条件通过`
- 理由：项目推进者确认，SystemVerilog 中一位无符号表达式赋给四位向量通常按赋值上下文宽度扩展，`F = A[0]` 本身不等同于 `F[3:1]` 没有驱动；模型关于“高位未驱动并显示 X/Z”的因果解释很可能错误。有限波形中的 X/Z 也可能来自 `F` 以外的连接、映射、数码管逻辑或未提供上下文，当前证据不足以锁定原因。
- 必须修改/是否复验：强化 HDL 提示政策，禁止仅凭宽度差异或有限波形断言未驱动、初始化或 X/Z 因果；完成离线回归后，是否追加真实复验作为独立决定，不能自动重跑已消费批次。
