## Acceptance criteria

- [ ] 两标签从同 draftRevision 开始编辑，CAS 败方不覆盖胜方；双方原文可恢复，存储失败保留内存正文并显示尚未保护。BroadcastChannel 不代替事务。
- [ ] VERSION_CONFLICT 读当前获准 head，保留本机原文/原确认基线/新服务正文；IDEMPOTENCY_CONFLICT 单列业务键冲突，不能偷偷替换输入再重发同键。
- [ ] RECOVERY_REQUIRED 后重读的新上下文与旧正文可比较；旧 ACK 不建立新确认头。缺恢复交接则显示不可用。
- [ ] 比较只读，选择/合并由学生明确发起；此后以新权威预期版本、当前受信代际、新键/seq 保存，旧 outbox 保留拒绝/旧事实，不自行迁代际。
- [ ] 选择期间第三方再更新时重新 CAS，保留新候选；不把用户一次选择当永远允许覆盖。暂停仅允许已有 active update，终态只读。
- [ ] 浏览器复现两标签写冲突、选择期间再冲突、服务 CAS 拒绝与恢复后比较；核双方正文、实际新请求以及旧上下文隔离，键盘可进入/离开比较。
- [ ] 工程与该切片浏览器检查记录准确结果；不记真实恢复或教学效果。
