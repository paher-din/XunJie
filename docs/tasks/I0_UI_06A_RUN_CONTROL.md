## Acceptance criteria

- [ ] 取消由学生明确发起，使用原 jobId、当前有效身份/受信代际与业务键；取消响应未知保存原请求，不换键补做。
- [ ] cancelling 是待确认；poll 的 cancelled 等权威状态才更新结束。网络 timeout 不假装已停、不释放执行资格。
- [ ] outcome_unknown/stale/断线时核原命令回执、run/job 与受信上下文，不自动执行新 run；缺原服务/恢复交接保持明确不可用。
- [ ] 重读到终态后仍服从服务状态/每 Attempt 单作业/全局槽位；前端按钮不替代服务调度。新运行必须由学生发起。
- [ ] 当前上下文与 poll 轮次守卫沿用 06；迟到 cancel/poll 不覆盖其他 run 或新代际。
- [ ] 浏览器复现取消受理但未确认、取消响应丢失、原运行未知、旧代际拒绝与迟到 poll；核没有自动第二次 run，状态/请求身份准确。
- [ ] 工程及本切片检查记录准备/真实范围，未执行不填通过。
