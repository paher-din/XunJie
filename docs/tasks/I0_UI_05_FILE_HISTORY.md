## Acceptance criteria

- [ ] 学生明确 recycle/restore，沿用 fileId/baseVersion/CAS/原幂等语义及 03 的原命令/ACK 事务；拒绝不丢草稿、不假成功。
- [ ] 同路径重建是新实例；旧快照/运行保留旧 fileId，草稿/model/历史按实例隔离。
- [ ] 恢复路径被占用时保留双方，不覆盖/擅自 rename；学生显式处理当前占用后才能用新的命令恢复。暂停/终态/无权限不可操作。
- [ ] 两快照或草稿/确认比较只读，展示身份/路径/版本和正文差异；无隐式写请求，不改源 model。
- [ ] 单侧/回收/历史缺失状态准确，不用同名新实例代替旧引用；原文 EOL/BOM/非 BMP 与 readonly diff 显示相容，不能仅因进入 diff 改摘要。
- [ ] 键盘能打开/切换/离开比较，使用实际 UI 交付和容器，不另造页面。
- [ ] 浏览器验证回收→同名重建→恢复冲突、合法恢复和只读比较，核实例、摘要及无写副作用；相应工程检查通过。
