## 2. D-01 的完整活动衔接建议

外部参考不直接作为活动规格。负责人已确认主项目 TextScope Core：stats/find/top；相关后续 TextScope Report：教师反馈后增加报告文件产出，验证复用和修订。四种功能保留在两次真实学习尝试中，符合 MVP 的主项目→反馈→相关后续任务闭环。学生全部在 Web 学生空间操作，先备已确定为函数/数组/指针基础；覆盖章节/支架由教师确认，原稿全书/35 小时/六阶段/自引用结构/固定权重不直接作为门槛。

| 能力线 | 目标/观察 | 保存方式 |
| --- | --- | --- |
| 学科知识与技能 | 从字符串扫描/指针与动态数据、FILE/参数与多文件组织中选少量具体目标；解释边界与设计，在明确条件下检查。低级 POSIX I/O 为拓展候选 | 固定作品/可信检查/短解释/变式引用，注明帮助和适用范围 |
| 项目能力 | 比较词频结构、解释复杂度，设计反例、处理失败、验证和修订，交付可重复构建与文档 | 选择依据、测试预期/实际、修订/交付事实；不以事件数量认能力 |
| 人机协同与 AI 素养 | 明确求助对象，核查建议并记录采用/调整/拒绝的理由 | 实际消息/帮助与核查过程；没有发生的行为保持未知，不为凑证据造 AI 错误或强迫使用 AI |

作品结果、三条能力线、帮助条件与未知分别表达；教师确认正式课程量规，原五维权重只保留为参考。教师按实际活动选里程碑，学生能比较路线/回看修订，Agent 分析不自动决定独立掌握或逐级解锁。

日常帮助允许概念/局部定位/相邻示例/结构比较/核查设计，拒绝整份代做；关键选择、修改、运行、提交由学生发起。可信课程检查进行时关闭不允许的辅导；解释/变式政策事先说明，无系统内帮助不等于无外部帮助。外部线下答辩适配成 Web 工作区的必要解释与教师复核，不新增语音/视频流程。

Core/Report 的活动划分与先备已确认；两个活动使用独立 ActivityVersion/Attempt，读取相关有效反馈，由学生主动继续原作，保留旧提交。“下划线成词/大小写选项/低级 I/O”留作将来教师可选变式。具体目标与 TS-P01～06 的行为/参数/产物补充仍待负责人确认。

### 教材与资源交付

教材按负责人提供的第 1～8 章映射选必要段落；整理原创导学、段落/页码引用、教师获准文字和 ASCII 测试数据，导入 TXT/Markdown。公开任务/例子给学生与辅导 Agent，私有测试/答案仅教师和可信验证器读取。

整本 PDF 未纳入仓库，抽取样本存在乱码；没有在 G0 自动 OCR、整包发布或发送教材到模型。团队开发契约、公开 TextScope 规格和合成用例可以从本仓库独立阅读；正式资料正文的交付责任归教师/A，真人活动开放前完成引用/可见性与内容审阅。

仅合成验证可以先准备；账号访问/凭据配置、付费样例调用须分别获得操作授权。真实数据发送前，教学/技术负责人确认实际 API 数据条款、处理/留存范围与告知：仅当前学生的必要代码/主动消息、获准课程材料及有效状态，不包含身份凭据/其他学生/私有答案。条件不满足时保持人工辅导与保存，不能把供应商选择当作处理条件已经落实。

### G0-C15：Web 运行参数与 Report 产物接缝（待确认）

学生在工作区写 C 程序，但该学习对象需要练习 argc/argv。C 的运行请求提供课程约束的操作/参数输入，绑定快照中获准的数据文件实例；后端将 stats/find/top/report 等操作映射到固定可执行文件和参数数组，不接受 shell、编译命令、镜像或任意宿主路径。未知命令/缺参等程序错误由课程批准的错误参数样例测试，不能为了参数测试开放宿主终端。真实 UI 最后接入对应业务能力，不由本任务另做参数页面。

TextScope report 产生文件，当前 RunRecord/可信验证描述尚未把其回取字段说清。最小补充：课程 profile 列 approvedResultFiles；作业结束/隔离单元确认终止后，C1 仅回取该白名单中的普通文本文件，拒绝符号链接/逃逸，规范化路径再核验，记录 runId/snapshotId、相对名、正文/hash/字节数及来源。编译/运行 stdout+stderr 和实际回取文件合计不超 NFR-03 的 64 KiB 输出，临时写区仍 128 MiB，超限不伪装成完整报告。

可信验证器在学生进程之外核报告；C2/records 保存不可变 RunRecord 的结果引用并按本人/课程角色裁剪，下载/读取再次授权。未生成/不可回取标 missing/incomplete，与读取失败、环境故障分别记录。学生查看结果不会自动新建/覆盖 ProjectFile；要保存为作品须学生另发显式操作。实际 UI 最后接入只读产物呈现，不由执行 Agent 新建替代页面。

这是运行结果/可信检查已有业务的必要细化，不增加任意文件下载、学生 shell、自动写作品或扩大输出限额。A/C/B 会审后合入 TECH 和受影响的 AC-04/10/12/15；实现依赖 C1/C2，未验收。
