# C0 学生工作区领域用语

这里界定课程内个人项目的作品、过程和结果用语。定义提取自既有产品基线及 C0 已确认讨论，仅供 C0 阅读与协作；不替代团队共享词汇表。

## Language

**尝试（Attempt）**：
一名学生围绕一次分配的固定活动版本开展的一段项目学习过程。相关后续任务属于新的尝试。
_Avoid_: 会话、聊天、运行

**文件实例**：
某次尝试中具有独立历史的一份项目文件。同名重建的文件属于另一个实例。
_Avoid_: 文件路径、文件名

**本机草稿**：
学生当前保留在本机、尚未取得服务确认的作品内容。
_Avoid_: 已保存作品、已上传作品

**已确认作品**：
服务已经确认保存的当前作品内容。它可能比最近一次运行或提交所用的作品更新。
_Avoid_: 最新快照、当前运行源码

**作品快照**：
一份固定且可追溯的多文件作品版本，可作为求助、运行、检查或提交的共同对象。
_Avoid_: 当前路径、当前草稿、最终答案

**过程采集**：
对当前项目逐次编辑及其他获准过程信息的记录。
_Avoid_: 作品保存、全部学习过程观察

**功能数据**：
为保存作品、处理显式求助、运行、检查和提交而必要的作品、消息与结果。
_Avoid_: 逐次过程日志、采集开启证明

**采集空窗**：
相关过程信息因暂停、断线等原因缺失或无法确认的区间。
_Avoid_: 学生未行动、能力不足

**运行结果**：
一次实际程序执行的结果与发生条件。
_Avoid_: 课程通过、教师评价、掌握证据

**课程检查结果**：
指定课程规则下，对一份固定作品的检查结论及覆盖范围。
_Avoid_: 程序退出成功、环境就绪、正式评价

**环境就绪**：
指定工具链在相应验证条件下能够处理批准样例的状态。
_Avoid_: 学生作品正确、课程通过

**教师决定**：
教师对学习状态、反馈或后续教学作出的正式判断，保留理由、依据与适用范围。
_Avoid_: 模型候选、原始观察、运行成功

**运行取消请求**：
要求停止一次已发起运行的明确意图。
_Avoid_: 运行已停止、取消完成

**运行取消完成**：
该次运行及相关执行单元已确认停止，未完成的启动也不会让它继续运行。
_Avoid_: 取消请求已收到、暂时没有看到程序

**执行账本**：
独立执行端保存的作业接收、执行、取消与终止事实集合，其完整性指相关作业事实与关联覆盖。
_Avoid_: 作品备份、完整学习过程、能力记录

**运行结果未知**：
已有运行请求，但其是否执行、是否终止或最终结果无法核实的状态。
_Avoid_: 程序失败、学生答错、运行未发生

**恢复缺口**：
回退旧备份后，作品、消息、输出或引用内容无法从获准保留的数据中还原的缺失。
_Avoid_: 采集暂停、学生没有行动、由摘要恢复的原文
