## 1. A 要交付什么

A 的核心交付是：**教师能够设计并分配固定版本的项目，依据可追溯表现作出反馈和纠正，并让有效决定进入学生下一轮学习。** 认证、公共契约与事务能力服务于这条业务链。

落实为三组结果：

1. 真实权限：每个读写、模型读取、事件和导出都遵循身份、课程、资源、阶段与命令范围。
2. 教师设计链：资料 → 可编辑蓝图 → 三类检查与角色预览 → 教师确认的活动版本 → 指定成员分配。
3. 教师反馈链：原始依据/候选 → 有效学习状态 → 教师复核或纠正 → 正式反馈、修订许可或相关后续任务。

A 同时协调公共接口、共享文件和验收汇总。B 负责模型与教学分析，C 负责工作区、记录、作业和执行；两人的实现与故障修复仍由各自负责。实际 UI 接入放在最后，不新增前端设计任务。

最先要降低的风险是：权限只检查写接口、并发建议覆盖人工修改、教师纠正与旧动作失效分开提交、模型结果被误写成正式判断、跨模块整项互等。下面按这些风险安排交付顺序和测试。

这是一个人的优先队列，不能同时计算多项 A 任务的并行工期。A2 第二批外部条件未齐时，交付第一批后可以先做 A3；A3 外部条件未齐时，可推进 A4 的独立状态逻辑。待条件具备，再按阻塞下游的优先级回到未完成批次，记录实际顺序与未交付部分。

三个最需要提前交接的点：

- A1 的权限/事务入口先给 C2；C2 的统一作业与回执不能拖到 C3 才第一次提供。
- A4 的候选写入/有效状态读取先给 B3；A4 不等待 B3 产出真实分析才开始。
- A5 的教师修订许可与 C4 的学生重开按同一契约分别实现；双方不互等整个任务完成。

A2 暂停命令可以提前做状态与契约测试，但只改 Assignment 而未使相关作业失效，不能记为完整暂停功能已交付。教师起草不受 C1 未就绪阻碍，活动确认/开放仍必须检查真实运行就绪。

| A2.5 | 教师确认与不可变版本 | 再核验 revision、引用/规则版本及 C1 真实就绪；冻结活动相关版本；旧活动内容不能 PATCH |
| A2.6 | 分配、暂停/恢复与新版本使用 | 指定课程成员；固定旧尝试版本；分配控制同事务调用 C 的 epoch/失效能力，学生恢复不绕过教师暂停 |

**第一批交接 A2.1～A2.4：** 给 A3 可编辑草稿，给 B 获准材料/目标/政策投影；提供 C 校验任务归属所需的契约。**第二批交接 A2.5～A2.6：** C1 就绪和相应事务能力具备后，交出真实活动与分配/控制链。

发布前检查结果需能追溯所检查的草稿版本。确认时不能直接相信客户端提交的“已检查”或“环境 ready”；设计疑点保留教师处理说明，学习效果等未验证项不能变成事实。私有答案也不得进入学生或辅导 Agent 的错误信息、事件或预览载荷。

最小验证：旧 revision 编辑冲突、修改目标后量规/检查点影响可见、越权资源拒绝、私有资产投影拒绝、未就绪确认拒绝、活动原地修改拒绝、越权/重复分配、暂停与学生恢复竞态。环境 smoke 只支持运行就绪，不证明课程验收。

**A2 出口：** 教师能独立维护草稿；开放的每个活动有真实就绪依据与固定版本，分配/控制效果可验证。草稿部分已交付时不记整张 A2 或 G1 完成。

## 9. A4：有效学习状态与原子的教师纠正

**对应：** M-06、M-08、M-09；AC-07/08 主路径，AC-16 状态读取配合、NFR-04。

这是 A 最需要先验证正确性的业务部分。先实现状态与候选接口给 B3，再接 C3 的真实失效能力，不等 B3 完成模型提取。

| A4.2 | 候选接纳校验 | 核验课程/学生/目标 scope、原始引用、帮助条件、分析版本与预期状态版本；拒绝伪造、越权与旧分析直接写入 |

| A4.4 | 学生异议与教师确认/纠正/暂缓 | 校验本人或任课教师、目标版本、理由与引用；争议期间避免依赖该主张作强适应 |

纠正事务按 TECH_DESIGN 第 7.2 节落地，验证顺序如下：鉴权与版本检查 → 追加决定 → 新状态/相关 contested 标记 → C 的同事务失效 → 事件/必要作业 → 提交后通知。不能在提交前发出“纠正成功”事件，也不能先提交判断再用独立 HTTP 请求补取消。

同一幂等请求重放应返回首次结果；不能因它自己的首次写入已经增加 revision 而误判成新冲突。同键不同内容仍冲突。全流程依赖 C 的统一回执，不能另写一套业务去重。

最小验证：两名/两个页面并发复核只能一个当前版本写成功；事务中注入失败无半笔决定或失效；纠正时旧模型继续运行/完成/回执迟到，不能恢复撤回主张；已显示帮助不删除、不改写当时帮助条件。重复运行不累加掌握率，环境错不算知识错，引用缺口保留未知。

**A4 出口：** B 可以受控提交候选、读取有效状态；真实纠正与 C3 的失效在一个数据库事务生效，AC-08 服务端竞态可重复通过。已显示内容和真实 UI 的竞态仍在最后验收。
