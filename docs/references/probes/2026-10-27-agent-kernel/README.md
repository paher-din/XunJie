# Agent 内核接入探针

日期：2026-10-27。仅用于总体架构取舍的可复现研究，不是产品运行代码。

共同输入见 [fixtures.mjs](fixtures.mjs)。模型均为确定性替身，不连接真实提供商；包含 Chat、Responses、Messages 风格的完整原件、工具身份及不应丢失的 opaque 内容。它们用于核对桥接与持久边界，不能代替真实 SDK/提供商兼容性验收。

比较时区分上游自身提供的行为、循阶探针补充的机制，以及未执行的部分。不同框架使用各自公开接口接收同一语义输入；不将探针代码行数作为生产维护成本或稳定性的证明。

研究前提沿用[旧架构核对](../../2026-10-18-architecture-checks.md#内核取舍的工程判断)、[ADR 0002](../../../adr/0002-own-teaching-state-and-effect-control.md)和[实际端点评估](../../2026-10-23-model-endpoint-assessment.md#从目标推导模型调用层)：模型连接层已选择直接 SDK，内核尚未定；本轮补齐当时未做的接入和恢复证据，不重复真实端点测试。

需核对的情形：

1. 完整模型响应经持久保存后才能执行工具；中断/失败响应不执行工具。
2. 三协议原件经过序列化与恢复仍保持一致，通用消息只作为投影。
3. 已保存完整响应后重启，不重新调用模型来获取同一工具意图。
4. 工具已接收但回执丢失时，恢复按稳定命令身份查询，不重复副作用。
5. 等待外部工具时可持久退出，结果到达再继续；取消后的晚回执不复活运行。
6. 每次新模型调用前执行预算检查；执行前重新核对授权和对象依据。

候选固定基线：`@earendil-works/pi-agent-core@1.4.0`、`@earendil-works/pi-durable@1.4.0`；DeepSeek Harness 源码 `22ddee3792402c3e70ec5f86a63c3e3e895a2f60`。各探针需记录实际安装版本、运行环境、命令及输出。依赖只安装在临时研究目录，不修改应用依赖。
