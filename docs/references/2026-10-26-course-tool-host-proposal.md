## 平台、Agent 与教师的分工建议

平台执行可重复、可检查的程序步骤；Agent 理解需求、生成或修正工具内容；教师决定教学目标、检查教学是否合适并发布课程。Agent 可以调用平台准备命令，但命令的执行、状态与结果不依赖模型持续在线。

| 时机 | 平台直接完成 | Agent 参与 |
| --- | --- | --- |
| 选择已有工具 | 读取声明、组合参数、准备支持的依赖、执行固定自检 | 根据教学要求推荐工具与配置 |
| 创造或修改工具 | 构建、接口和资源校验、执行示例、汇总具体诊断 | 编写或修改界面、算法、说明、声明和示例 |
| 准备用于课程 | 检查本课程配置、材料访问、环境安排及所需能力 | 协助处理教学适配与需要语义判断的失败 |
| 教师预览 | 创建独立试用实例，记录真实准备和运行结果 | 协助设计试用情形、解释观察结果 |
| 学生进入活动 | 检查真实设备，执行已有准备、查询与恢复程序 | 在需要解释或重新设计时介入 |

只因新代码、相关依赖、配置或环境发生变化而重做受影响检查；不能把每次打开已就绪工具都变成一次 Agent 生成流程。自检发现代码能运行，不等于证明教学内容正确；教师预览也不代表所有学生设备已验收。

“需要工程接入”指平台开发者扩充尚未支持的系统、硬件访问或执行控制能力。例如，在已支持且允许装包的 Python 环境中加入兼容依赖，属于装配；接入现有执行器完全不能访问的硬件，则可能需要新增适配。新增界面、新算法、新课程不自动要求修改主工作区。

准备失败保留工具草稿、已完成配置和诊断；产品能修复的依赖或构建步骤由程序重试，需要改代码时交给 Agent，需要新平台能力时明确说明缺口。对结果未知或可能产生副作用的操作仍按原身份查询，不能以“自动修复”为由盲目重跑。

## 复用对象与状态归属建议

| 对象 | 负责什么 | 不承载什么 |
| --- | --- | --- |
| 教师工具库 | 保存可复用工具及其草稿、可用版本，供教师再次选用 | 全班学生的共享操作状态；公开市场发布 |
| 工具定义及版本 | 界面或算法、支持的输入输出、状态结构、资源与环境需求、样例、自检、声明的能力 | 某个学生的作品、答案、实验进度 |
| 课程发布内容 | 本课程选择的工具版本、配置、学生资源、教学策略与运行方案 | 工具库的可变“最新版”；教师私有原文的学生端副本 |
| 活动中的工具实例 | 归属、固定工具版本、作品引用、已保存状态、运行与观察引用 | 第二份独立的可变作品权威 |
| 教学产物实例 | 当前活动中的解释、交互页面或卡片及其可恢复状态 | 自动成为已发布的课程工具 |

同一工具用于两门课程时，复用定义并分别绑定课程配置；同一课程里两位学生使用时，各自拥有实例。教师预览也有独立实例。把某次页面整理进教师工具库时，应提取可复用实现与示例数据，不把学生答案或当时实验状态带给其他使用者。

建议创建即保存工具库草稿，检查通过形成可用版本；教师把选定版本加入课程，在课程发布时交给学生。入库、形成可用版本、发布到课程有不同含义，不要求教师为这些内部状态分别手工搬运文件。

## 最小宿主契约建议

受控组件、隔离生成页面与课程工具共享以下语义。进程内调用、iframe 桥接及 MCP Apps 适配可以有不同传输方式，不各自定义作品与恢复规则。接口名和编码尚未定稿。

| 接口组 | 最少需要表达的内容 |
| --- | --- |
| 绑定与生命周期 | 工具及版本、活动和实例身份、允许能力；每次挂载有新的连接身份；准备、就绪、失败、关闭视图分别表达 |
| 内容与状态 | 从工作区读对象；按依据提交状态变化；工作区返回本机保存确认及内容身份；恢复只使用已确认状态 |
| 命令与执行 | 声明参数及读写/执行效果；沿公共执行契约携带稳定请求身份、实际输入、范围、结果与回执；可查询、停止的能力按实际声明 |
| 观察与教学事件 | 结果绑定具体输入和运行；普通控件变化、学生主动回答、预测、确认分别表达，不把所有变化都当作学习证据或模型请求 |
| 引用与语义锚点 | 稳定来源、内容身份、类型化范围、当时可读副本；定位返回可用、已变化或不可用，不能按同名对象猜测替代 |

工具可只提供其中需要的能力。例如纯标注工具无需执行器；没有视图的算法无需面板；需要暂停和单步的模拟器应声明持续会话能力。工具清单是可验证的交付内容，主要由开发者或创作 Agent 产生，教师通过教学配置和预览操作它。

最小交付清单包含工具稳定身份和固定版本、宿主 API 版本、入口与资源内容身份、输入/输出和状态结构、允许调用的能力需求，以及示例与自检。需要执行时再声明环境、依赖锁定信息和有限作业/持续会话类型；无需执行的工具省略该部分。源码和构建依赖保留在创作侧，学生装载已准备的固定资源，不能每次开页再由 Agent 临时决定安装什么。

兼容已有宿主 API 和环境的新工具按声明动态加载，不重新构建主前端。内建组件可直接注册；教师或第三方提供的界面在隔离页面运行，计算进入获准的 Worker 或执行器。来源不直接决定权限；实际允许能力取工具声明、课程策略、当前主体与具体操作依据的交集。

视图可以即时响应交互，但“已经可靠保存”由工作区存储确认。每次状态写入携带所依据的状态身份，避免旧挂载或乱序消息覆盖新状态。工具自身的对象状态结构可扩展，宿主只要求结构可校验、可持久化并有版本；不能期望保存 HTML 就恢复任意脚本内部变量。

工作区保存作品和需要恢复的工具状态；执行器负责仍在运行的会话及真实检查点；临时焦点、浮层位置、DOM 与进程句柄不作为持久作品。再次打开视图不意味着重跑实验，恢复滑块也不意味着恢复了实验器内部状态。

非文本引用由对应工具提供最小适配：对象/观察身份、当时内容身份、语义范围、可读摘要和必要图像或数据副本。波形以信号和时间范围定位，图表以数据系列与点/区域定位，画布以对象身份或区域定位；不能把跨域 DOM 坐标假装成稳定语义。宿主复用引用展示、去重和草稿交互，工具负责解释自身对象。新工具若缺少必需的选择或恢复接口，在接入检查中明确指出，不能只因页面能显示就把完整工作区能力标为就绪。

## 更新、停用与恢复

- 工具库新版本先通过检查和预览。形成可用版本后，页面提示仍使用旧版的课程任务及当前版本，教师选择同步哪些任务；只编辑草稿不自动改变课程。
- 同步先检查所选任务的配置与环境兼容，成功才修改任务后续活动的版本绑定；失败保留原绑定并指出需要处理的配置。之后新开始的活动使用新版，已开始的活动继续固定原版。本轮不加入进行中活动跨版本迁移。
- 同步反馈按任务说明已更新、未选择或失败，不以部分成功冒充全部完成。工作区不要求学生处理版本迁移或决定执行节点。
- 关闭一个工具视图释放该连接与订阅；是否结束运行按已声明生命周期处理。课程停用工具、撤下可用版本和删除学生数据是不同操作。
- 工具仍被课程或既有活动引用时，保留相应固定资源以供继续使用或恢复；从教师工具库移除入口不连带删除学生数据。停止新使用与彻底清理资源分别处理。
- 因兼容性等原因不能再运行旧版本时，保留可读的作品、引用副本和历史结果，并说明哪些交互无法恢复；不能冒充仍可继续原实验。
- 生成中的页面先预览；通过结构和能力检查后才启用交互。Agent 修订该页面时形成新内容版本，优先在原页保留可对应的输入；不能兼容时保留原页、另开新版并说明差异。旧实验和已发送引用仍指向原内容，不能让页面更新改写它们。

## 三个契约检验例子

### 数字逻辑 ALU

复用编辑器、虚拟板和波形视图；课程选择固定工具、环境与活动配置。学生实例记录作品引用、实验输入和观察身份，波形引用用运行/观察、信号与时间范围表达。生成比较页读取获准的观察并可请求课程允许的验证，不能把说明图冒充真实仿真结果。

### 数据分析活动

教师创建处理某种实验数据的新算法与图表界面，保存到工具库。课程甲选择数据和字段，课程乙使用同一工具版本但配置不同数据；每位学生的筛选、图表选择、分析作品和运行记录独立。新依赖在已支持环境内装配；大型文件引用资源对象，状态中保存筛选与资源身份，不把全部文件塞进每次界面事件。

这是检验公共契约的设计反例，不是当前已支持任意 Python 包或数据分析工具的实现声明。

### 无需执行的材料标注

学生给材料中的论证、图形或表格做标注，产出结构化作品与引用；工具只需内容、状态、选择与语义锚点，无需伪造编译或实验运行步骤。Agent 按实际阅读到的材料版本讨论，不要求每项学习活动都有执行器。

## 外部能力的接入建议

OpenIntelligentUI 提供渐进预览与最终 iframe 渲染的可复用代码，但依赖其应用壳，且不提供完整进度恢复或通用非文本引用。建议复用其片段处理与渐进展示机制，渲染器限定为可替换适配；沿用本项目已有 iframe 桥接基础承接实例、状态和选区，不移植整个 React renderer、聊天后端或 CopilotKit 状态。Websandbox 不作为本轮必要依赖；原生隔离页面足以表达本轮所需的显式消息接口，实际抽离构建和浏览器行为仍须验证。[源码与证据](2026-10-26-course-tool-host-research.md#openintelligentui可抽取的东西和真实缺口)

MCP 用于外部工具与资源接入，MCP Apps 用于符合其规范的外部交互界面；两者通过适配映射到同一课程能力和状态契约，不要求每个内置或教师工具都先实现 MCP 服务。Apps 的模型上下文更新与工作区保存确认分开，Stable 与 draft 能力也分别核验。[协议事实](2026-10-26-course-tool-host-research.md#mcp--mcp-apps责任实际落在哪里)

Skills 描述如何使用能力及课程允许的教学方法，不替代执行权限或状态协议。学生侧 Skills 只携带开放的说明及资源引用，教师私有版本留在教师侧；不能因为说明文件引用了某份材料，就让学生工具或 Agent 自动获得它。具体操作仍由宿主和执行端检查。

教师私有原文不进入学生工具包、前端资源或学生 Agent 上下文。需要隐藏评测时，评测侧读取私有材料，学生侧只得到课程允许的结果与反馈；工具声明和 MCP 可见性标记不能替代服务端资源访问检查。

需要保持私有的评测材料不能随运行包下发到学生设备。此类评测由教师侧或课程明确配置的受控评测服务执行；学生本地练习使用开放样例，仍按既定本地运行方案开展。课程没有私有评测需求时，不因此增加远端评测服务。

## 后续验证

负责人已确认整套工程方案，本文件保留为该次讨论材料。以下是实施与验收义务，不冒充已有生产能力。

1. 工具接入：一个教师自建工具只通过固定清单、资源和已有执行环境装入课程；不修改主工作区的课程分支。验证自检失败、修复及学生设备准备。
2. 状态与引用：同一工具两个学生实例独立；重开恢复已保存状态；旧挂载消息不覆盖新状态；非文本选区保留来源副本；中断实验不自动重跑。
3. 教师工具库：新版本提示所有受影响课程任务；只更新选中且兼容的任务；新活动使用新版，已开始活动继续原版；停用不删除学生作品。
4. 生成内容：预览到交互的切换、修改后保留输入、不兼容时另开新版，以及旧引用/观察归属都须实测。OpenIntelligentUI 局部代码的构建、许可声明和浏览器隔离按实际引入范围检查。
5. 资源和外部适配：学生侧无法从工具、Skills 或 MCP 绕过课程资源范围；MCP Core、Apps、SDK 与具体宿主组合分别验证，不能用 draft 示例冒充稳定支持。
6. 教师准备体验、真实应用浏览器验收与教学效果分别记证据；本次仅完成源码/规范阅读及文档检查，未执行上述产品集成验证。
