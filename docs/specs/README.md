# 并行实施规范

这三项是负责人于 2026-10-23 明确授权实施的范围，与模型接入和总体架构研究并行。规范依据已确认的产品要求，限定在可复用前端能力与只读开发工具；它们不代表相关研究议题已经解决。

| 实施范围 | 规范 | GitHub 实施票 |
| --- | --- | --- |
| 普通文本与代码选区、工具条、引用区 | [选区引用](workspace-selection-references.md) | [工作区选区工具条与上下文引用](https://github.com/paher-din/XunJie/issues/122) |
| IP、文字与卡片的受控展示及旧脚本适配 | [引导展示层](guidance-presentation.md) | [IP 教学引导展示层](https://github.com/paher-din/XunJie/issues/123) |
| 环境事实、配置存在性检查、脱敏输出与复现记录 | [开发自检](development-doctor.md) | [开发环境只读自检与复现记录](https://github.com/paher-din/XunJie/issues/124) |

前端交付包括实际复用的组件、来源或课程适配和开发验收页；后端同步、教学状态机和模型接入不包含在这两项实现中。开发工具记录现有环境，不修改环境，也不决定未来部署。各项分别记录工程检查、浏览器验收和未验证范围。
