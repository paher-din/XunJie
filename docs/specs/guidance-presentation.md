# 可复用的 IP 教学引导展示层

状态：已授权实施的展示范围。日期：2026-10-23。

## Problem Statement

学生端已经有 IP 形象、动画、文字气泡和教学卡片外观，但现有引导层把固定课程锚点、卡片注册表和预置步骤混在一起。后续 Agent 要持续引导时，展示层应能接收任意课程提供的内容，不必重写形象或复制整套引导代码。

## Solution

从现有引导层提取可复用的展示组件。调用方提供当前展示项、内容、目标位置、动作及显示状态，组件负责 IP、文字或卡片的呈现，并回传真实操作。原有课程脚本通过薄适配继续使用同一组件。何时介入、给什么帮助以及怎样判断学习进展由外部控制。

提供独立开发验收页，通过受控输入切换文字、卡片、锚点、隐藏和忙碌等情形，并显示组件回调；它使用真实组件，不伪造主动教学。正式构建移除验收入口与样例。

## User Stories

1. 作为学生，我希望不同课程中的引导使用一致的 IP 和气泡，以便形成稳定的学习体验。
2. 作为学生，我希望看到与当前展示项对应的简短文字，以便清楚理解提示。
3. 作为学生，我希望引导能够容纳交互卡片，以便在同一工作区继续探索。
4. 作为学生，我希望提示出现在相关内容附近，以便理解它所指的对象。
5. 作为学生，我希望目标滚动或布局变化后提示仍处在合适位置，以便不与内容脱节。
6. 作为学生，我希望目标暂时不可见时提示不强行滚动页面或抢走焦点，以便继续当前操作。
7. 作为学生，我希望能够使用调用方提供的继续、暂不或关闭动作，以便表达自己的选择。
8. 作为学生，我希望每次操作只对应当前看到的提示，以便不会错误回应后来的新提示。
9. 作为学生，我希望连续渲染或重复状态更新不会被当作我的回应，以便学习记录真实。
10. 作为学生，我希望忙碌、等待和安静状态能够被清晰展示，以便知道当前发生什么。
11. 作为学生，我希望收起引导后可以按产品提供的入口重新打开，以便自己安排注意力。
12. 作为学生，我希望在窄窗口中仍能读完文字、操作按钮，以便提示不会超出屏幕。
13. 作为学生，我希望键盘能够操作所有引导动作，以便不依赖鼠标。
14. 作为学生，我希望减少动效设置被遵守，以便避免不必要的移动。
15. 作为课程开发者，我希望传入自己的卡片内容和目标，以便不依赖数字逻辑课程的固定面板。
16. 作为应用开发者，我希望展示组件通过回调报告操作，以便未来教学运行时接管后续流程。
17. 作为维护者，我希望已有脚本通过适配复用新组件，以便不同时维护两套 IP 呈现逻辑。
18. 作为维护者，我希望卸载组件后监听和计时器被清理，以便页面切换后不出现旧提示或旧回调。

## Implementation Decisions

- 复用已存在的 IP 形象、动作播放能力和设计 token，不重新生成形象或引入另一套动画系统。
- 通用展示组件不导入固定课程卡片注册表、工具枚举或预置教学步骤。课程适配器负责把已有脚本转换成局部展示输入；旧入口通过该适配器复用新组件。
- 展示输入有明确身份、文字或卡片内容、可选目标、显示状态以及动作集合。该接口只是前端展示接口，不命名为最终教学协议，也不承担活动状态机和持久化。
- 调用方决定展示、替换和隐藏。组件仅在明确用户操作时回传该展示项身份及动作，不因挂载、动画结束或内容可见而报告学生理解、确认或掌握。
- 不在组件内创建模型请求、工具命令、教学队列或学习证据。卡片自身的业务由调用方提供，展示层不获得课程数据写入权限。
- 目标以调用方提供的可解析位置或元素边界定位；组件负责在自身显示范围内布局，响应滚动和尺寸变化。目标不可见或无法解析时回到明确的安静位置或普通非锚定展示，不主动滚动、不切换课程面板、不抢焦点。
- 保留已有气泡和卡片视觉层级，避免卡片超出可用视口。长内容可滚动，操作区可到达；点击展示动作不会意外穿透到工作区工具。
- 回调携带实际展示身份。替换和隐藏使旧展示失效，延后动画或旧事件不能错误作用到新项；重复渲染不会重复回应。
- 键盘焦点遵循普通交互规则，不因新提示自动移动；操作具有可访问名称。减少动效时保留内容与操作，停用非必要动画。
- 现有引导脚本的适配只保存当前演示行为，不将其固定步骤、锚点或“下一步”等逻辑提升为新的教学要求。

## Testing Decisions

- 主要测试切入点为真实浏览器中的引导展示验收页：外部更新展示输入，使用真实 IP、文字、卡片和操作回调，断言可见内容与实际事件。
- 沿用项目已有 Playwright 和 IP 动作测试。纯布局边界可用少量确定性测试，浏览器验证定位与交互，不依赖截图像素完全相等。
- 覆盖文字与卡片两种呈现、内容替换、显式隐藏与恢复、无目标和目标失效、滚动/尺寸变化、窄窗口及长内容。
- 覆盖当前展示身份、每次用户操作恰好一次回调、旧展示不会回应新项、重复渲染和动画完成不会自动生成回应。
- 覆盖键盘使用、焦点不被抢走、减少动效，以及卸载后的监听和计时器清理。
- 验证旧课程脚本经过适配后仍能显示和推进，通用组件本身不包含课程分支；验证展示操作不会发起模型、保存或实验请求。
- 执行学生端类型检查、构建及相关既有 IP 回归。正式产物不包含开发验收入口与样例。

## Out of Scope

- 主动介入策略、教学计划、持续教学状态机和学生画像。
- 教学证据持久化、最终 TeachingAction/UIIntent 协议与 runtime 接入。
- 新卡片生成系统、自由 HTML 沙箱、课程工具 SDK 和插件市场。
- 修改 IP 品牌形象、重新设计整页布局或扩展教师端产品。
- 教学效果验证。
