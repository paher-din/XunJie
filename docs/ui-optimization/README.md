2026-10-19。按本轮确认稿完成文字层级、Agent／设置控件及课程／导航优化。实现位于学生端；设计规则维护于 [DESIGN.md](../../DESIGN.md)。不包含教师端与工作区布局重构。

## 已交付

- 保留霞鹜文楷、品牌色和首页模块顺序；统一首页与独立 Agent 的标题字重、小字尺寸及文字颜色角色。首页问候维持 28px／600，Agent 正文为 15px／1.7。
- 独立 Agent 正文和输入共用 780px 宽度上限；输入使用轻面板阴影和既有焦点柔光。学生设置减轻思考强度分组装饰，统一字段、分段选项和行内保存按钮尺寸。
- 模型配置状态固定在操作组下方。只有保存得到确认且版本匹配时才显示成功；失败保留当前配置和原因，重新读取清除旧成功提示，管理员限制保持可见。学生页显式启用该呈现，教师复用组件仍使用原默认分支。
- C1：课程封面与回退色块统一 128px，同排卡片底部操作对齐。
- C2：任务说明为 13px／1.7，整理标题、说明及底部操作间距；缺失进度、截止或目标时不补造数据。
- C3：课程查询参数变化保留当前筛选。选课与直接课程链接定位任务标题；键盘选课聚焦标题，返回恢复触发卡与历史滚动位置。首次异步布局变化时校正定位，用户开始操作后停止跟随。
- C4：按课程区域实际宽度确定列数和工具栏换行；课程最多三列、任务最多两列。
- C5：未手动选择时，窗口 <1024px 默认使用既有 60px 轨道，≥1024px 展开 248px 侧栏；手动选择在当前外壳会话中跨窗口和页面保持。隐藏导航使用 inert／aria-hidden；轨道浮层关闭后焦点返回入口。

当时最终源码在 Node.js 24 的学生端工程完成类型检查、测试与构建；工程现位于 `apps/web`。当前统一从仓库根复跑 workspace 检查：

```sh
npm ci
npm run typecheck
npm test
npm run build
```

2026-10-19 的结果全部通过：56 个测试文件、680 项测试。新增模型状态回归测试覆盖确认版本、保存失败、未读取配置及管理员限制。构建保留既有的部分 chunk 超过 500 kB 提示；差异空白检查通过。上述历史结果不代表迁移后的新验证；当前完整工程检查使用根 `npm run typecheck`、`npm test`、`npm run build`。

本地准备模式浏览器检查：

- 首页、Agent 与设置浅／深色，以及 1024px 换行；工作区未命中新加的局部样式。第一部分曾比较工作区 163 个元素的字体、颜色、圆角和间距，结果一致。
- 1440／1280／1024／1023／900／768px 默认导航、手动切换及跨页保持；1440／1280／1024／768px 默认状态下课程为 3／3／2／2 列。768px 收起时主卡宽 698px，课程两列各 318px，任务单列 644px，无页面横向溢出。
- 键盘进入／返回、课程筛选保留、浏览器前进／后退、直接课程链接；浅／深色首次布局稳定后标题距主卡顶约 25px。用户滚动后窗口变化不会强制拉回标题。
- 历史、搜索、归档浮层的打开聚焦、Escape／外部关闭回焦；自动切换导航时焦点移出隐藏区域；工作区保持沉浸模式。
- 实际生产构建搭配隔离的合成配置接口，验证失败、等待确认、确认成功和重新读取状态；没有连接真实模型服务。
