# I0-UI 前端接入用语

## Language

**界面任务**：学生界面中用于寻找和进入一项项目要求的展示对象。
_Avoid_：把界面 taskId 当作分配、尝试或作品身份。

**分配（Assignment）**：教师将一个固定活动版本交给特定学生的安排，包含其当前可用性。
_Avoid_：课程名称、任务卡片、学生作品。

**尝试（Attempt）**：一名学生围绕一次分配的固定活动版本开展的项目学习过程。
_Avoid_：聊天会话、页面、单次运行。

**文件实例**：一次尝试中具有独立身份和历史的文件；同名重建属于另一个实例。
_Avoid_：文件路径、文件名、标签页。

**本机草稿**：当前保留在本机、尚未取得服务确认的作品内容。
_Avoid_：已确认作品、已上传证据、快照。

**作品原文**：学生作品实际保存的文本，保留学生没有修改的内容。
_Avoid_：编辑器显示文本、格式化预览、运行输出。

**显示文本**：用于查看和编辑作品的呈现内容，可与原文的呈现方式不同。
_Avoid_：已保存字节、确认作品、原始证据。

**已确认作品**：服务已经确认保存的作品内容，可能与当前草稿或最近运行所用内容不同。
_Avoid_：最新草稿、运行源码、最终作品。

**作品快照**：固定、可追溯的多文件作品版本，供运行、求助、检查或提交引用。
_Avoid_：当前文件路径、编辑器当前内容。

**准备场景**：使用明确合成材料和确定性响应验证前端行为的开发场景。
_Avoid_：真实课程分配、正式学习记录、真实服务验收。

**运行结果**：一次程序执行的实际结果及发生条件。
_Avoid_：课程通过、正式评价、学生掌握。

**本机请求记录**：本机留存的、明确关联某次业务操作的提交意图与输入事实。
_Avoid_：服务公开历史参数、当前控件值、运行已发生的证明。

**不可回取**：当前获准来源没有提供所需内容。
_Avoid_：内容为空、成功、可以猜出的值。

**运行取消请求**：要求停止已经发起的运行的意图。
_Avoid_：运行取消完成。

**运行结果未知**：已有运行请求，但其执行、停止或最终结果尚无法核实。
_Avoid_：运行未发生、程序错误、学生答错。

**来源版本**：一次前端导入或设计同步所采用的、可再次取回的已提交设计成果。
_Avoid_：设计工作副本、界面最后更新时间、当前主仓库作品版本。
