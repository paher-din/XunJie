# 固定版本导入前端，业务在主仓库维护，设计后续按差异同步

2026-10-11，前端接入成员 Robert 明确要求将这条接入路线写入执行任务。首次将 Design 的 `app/` 已提交子树导入 XunJie 的 `apps/student/`，固定可复核的来源 commit；此后 XunJie 维护业务接入代码，Design 继续迭代视觉设计。后续以“上次已接收来源 commit → 新来源 commit”的差异审阅并选择性同步，禁止整包覆盖目标目录。这让团队无需 Design 的本地目录即可构建应用，也保留主仓库业务接入改动。

不采用长期运行时链接/子模块，避免团队启动依赖另一个 checkout；不采用每次整包覆盖，避免丢失主仓库的保存、认证和运行接入。代价是需要记录来源版本、处理同文件的视觉/业务冲突；不能承诺后续同步自动无冲突。

上述目录及同步办法是本批确定的前端接入指令，不再作为待选择建议。实际来源选择、清单和冲突处理由 01 记录；本文不变更主仓库业务架构、A/B/C 分工或 Design 的历史 ADR。当前仅完成文档，没有执行导入。依据与执行约束见[接入准备记录](I0_UI_PREPARATION.md)。
